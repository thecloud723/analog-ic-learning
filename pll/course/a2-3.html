如何从原图读出纠偏方向

REF 领先时，较宽的是 UP。电荷泵把正电流送入环路滤波器，控制电压上升；在正 VCO 增益下，VCO 频率升高。FB 领先时，较宽的是 DOWN，控制方向相反。两路同相同频时只留下复位相关的短脉冲，不代表仍有持续净电流。

频差要跨多个参考周期观察：VCO 反馈偏快时，FB 边沿会逐周期漂移；个别 UP/DN 片段不能替代平均趋势。Fig.81 明确显示，单周期方向可能暂时不符合最终纠偏方向。

本课程理想事件模型 · 脉宽

令 Δt 为 FB 边沿相对 REF 的到达时差，treset 为本实验设置的复位延迟。仅在本页理想、无门延迟偏差的事件模型中：

REF 先到：wUP≈|Δt|+treset,wDN≈treset
FB 先到：wDN≈|Δt|+treset,wUP≈treset

这些近似式对应当前 A-INT-06 模型，不是 JKU 给出的通用非理想 PFD 方程。JKU §7.2 对真实图示说明：两边沿都到达后才复位，脉冲长度与相位到达差相关。

Explain · 由边沿事件到闭环纠偏

REF 与 FB 的上升沿分别置位 UP、DN。后到边沿也到达后，复位延迟结束时两路一起清零。REF 领先时 UP 脉冲较宽；FB 领先时 DN 脉冲较宽。

UP → CP 净充电 → 环路滤波器电压上升 → 在正 VCO 增益假设下频率上升；DN 则相反。这是控制方向解释，本页模型不计算实际电流、电容电压或频率增益。

同相同频时，两路短脉冲主要与复位逻辑时延有关。多周期频差要看边沿漂移和平均脉宽；Fig.81 提醒单周期不保证都呈现长期方向。
