Explain · 两个触发器记住谁先到

REF 上升沿置位 UP，FB 上升沿置位 DN。两路都高后，理想 RESET 延迟计时；到期时 UP/DN 同时清零。边沿同时到达时按 REF、FB、RESET 的可见顺序逐步显示。

连续频差需要看多个周期：100 MHz REF 与 99.9 MHz FB 比较时，FB 周期较长、边沿逐周期落后，UP 脉冲总体加宽。提高 FB 频率后方向相反。

UP → 电荷泵净充电 → VCTRL 上升 → 正 Kvco 假设下 VCO 加速；DN 则反向。本页只解释定性方向，不计算电流、电压或频率步进。
