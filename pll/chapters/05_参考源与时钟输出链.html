8 节

完整的参考与输出链

PLL 的锁定条件发生在鉴相器输入端。参考源、参考分频器、反馈分频器以及输出分频器处于不同位置，不能互相替代。

锁定时，PFD 比较 fPD 与 fVCO/N。输出分频 ÷D 位于反馈环路之外时，改变 D 不改变 VCO 的锁定频率；若反馈点位于输出分频之后，结论必须重新推导。

位置信号作用
输入源fREF提供稳定的时基，性能由参考源与供电等条件决定
参考分频后fPDPFD 比较更新速率
振荡器输出fVCO受环路调节的高频时钟
输出分频后fCLK送往负载的时钟；另需考虑 Buffer 与分配网络

真实参考与输出链：ADF4351

真实产品同时存在参考分频、反馈分频和输出分频三个不同位置。REFIN 的 Doubler 与 ÷2 作用于 PFD 参考输入；N Counter 位于反馈回路；输出 ÷DOUT 则把本振频率转换成需要的端口频率。

参考源及输入条件

参考时钟可以由晶体振荡器、外部时钟源或片上受控时钟链提供。PLL 通过反馈跟踪参考，但不会把参考源中的所有噪声自动消除。

参考端的基本规格

设计/测试字段定义与测量
输入频率范围可保证参考时钟路径正常工作的频率区间
单端/差分幅度在指定共模、终端和测量负载下定义
输入 Slew Rate阈值交越附近的电压变化率 dV/dt，决定电压噪声到时间扰动的敏感度

阈值附近的小噪声近似：σv 为 RMS 电压噪声，σt 为等效 RMS 时间扰动。

阈值交越 Slew = 0.20 V/ns，等效输入噪声 2 mV RMS，则边沿时间不确定度约为 10 ps RMS。

适用条件

上述换算用于局部线性边沿与小扰动估计，不能直接等同于完整 PLL 的输出抖动。输出抖动还取决于环路噪声传递、VCO 本底噪声和时钟输出链。

参考分频器 R

参考分频器每收到 R 个输入周期，产生一个比较周期。因此 R 改变的是 PFD 的比较频率，不是最终的输出分频比。

10 MHz 晶体参考时钟经过 R = 50，得到 200 kHz 的 PFD 比较频率：

在普通整数-N 合成器中，若需要 200 kHz 的频率调节步进，可用该 fPD 配合整数 N 实现。更复杂的分数合成不受这个整数步进限制。

判断：参考分频 R 从 1 增大到 2，并保持 N 不变，VCO 锁定频率如何变化？

由 fVCO=N·fREF/R，R 翻倍使 fPD 和 fVCO 均减半。

反馈分频 N 与 Prescaler

PFD 无法直接对两个频率相差很大的时钟做相位比较。反馈链把 VCO 输出分频到与参考比较频率相同，并提供频率合成比。

当 VCO 频率超出后级可编程计数器能力时，常在可编程分频器前加入固定或双模 Prescaler。固定 P 与后级整数计数 N 的简单串联结构满足：

但简单固定预分频会使频率分辨率变为 P·fPD。采用 P/(P+1) 双模预分频和 A/B 计数可以恢复更细的整数步进；其计数约束和实际实现另行讲解。

例题｜预分频的比较

fPD = 1 MHz，P = 4，后级 N = 400，则简单固定 Prescaler 合成频率为 1.6 GHz。将 N 增加 1 时，输出步进是 4 MHz，而非 1 MHz。

参考倍频与输出分频

查看来源原图

部分时钟链在参考路径使用倍频，提高 PFD 比较速率。一个经典办法是利用 XOR 与延迟生成两个半周期内的切换事件。

输出分频器通常位于 VCO 后。多个分频输出能提供不同频率或相位关系，但频率正确不保证输出端与参考输入端零延迟对齐。

输出 skew 还受分频器复位/相位同步方式、时钟 Buffer、布线及负载影响。PLL 在 PFD 输入处的相位锁定，不等价于芯片输出端的零相位差。

两路输出分别由 ÷2 和 ÷4 产生，是否一定保持确定的相位关系？

分频器可能有不同的初态和复位行为；输出负载、Buffer 和路由也会引入差异。

分频与频率的计算例题

例题｜一套 PLL 产生两路时钟

REF = 100 MHz，R=1，希望 VCO=1.6 GHz，同时输出 800 MHz 和 400 MHz。应使用 N=16，并在 VCO 后分别选 D1=2、D2=4。

例题｜参考变化但目标 VCO 不变

REF=100 MHz，R=2 得到 PFD 频率 50 MHz。若仍要求 fVCO=1.6 GHz，N 应变成 32。

整数-N 的可合成性

若 R、N 都必须为整数，目标频率不一定能够精确达到。对不能整除的目标频率，需调整参考频率规划或使用 Fractional-N 等方案。

商业芯片频率规划算例

采用 ADF4351 的可编程分频定义：D 为参考倍频使能，T 为参考 ÷2 使能，R 为参考分频比；INT/FRAC/MOD 定义反馈有效分频比。需要额外注意：数据手册里的 RFOUT 公式在相应段落首先表示 VCO 输出，端口经过输出分频之后还需再除以 DOUT。

例题 5-E：25 MHz 参考 → 625 MHz 输出

REFIN = 25 MHz，D = 1（倍频），T = 0，R = 5，INT = 250，FRAC = 0，DOUT = 4。

fPFD = 25 × 2 / 5 = 10 MHz；fVCO = 10 × 250 = 2500 MHz；fRFOUT = 2500 / 4 = 625 MHz。本振处于 ADF4351 的 2200–4400 MHz 范围内。

在环路带宽内，参考相位噪声通常会传递到 PLL 输出，且与分频/倍频比相关；具体大小由噪声传递函数决定。
