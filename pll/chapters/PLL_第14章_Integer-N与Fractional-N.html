Integer-N 与 Fractional-N

8 节

Integer-N：输出频率只能落在参考频率的整数倍

锁定时，反馈分频时钟与参考时钟在 PFD 输入端同频。整数-N PLL 的反馈分频比 N 是整数，因此输出频率只能以 fPFD 为间隔变化。

fOUTN=fPFD⇒fOUT=NfPFD

优点

  • 分频值固定，反馈路径直观。
  • 没有小数调制器产生的分频序列噪声。
  • 参考频率与信道间隔匹配时很合适。

限制

  • 频率步进就是 fPFD。
  • 要更细步进，通常需要降低 PFD 频率。
  • 较低 PFD 频率可能牵制环路带宽、锁定时间和噪声设计。
例题：fREF=100 MHz、R=1，则 fPFD=100 MHz。输出可以是 6.0 GHz、6.1 GHz、6.2 GHz……但不能直接设成 6.025 GHz。

如果把 R 改成 4，PFD 降为 25 MHz，频率网格也变成 25 MHz。6.025 GHz 仍然不在这个整数网格上。Integer-N 的限制来自“整数倍”本身，而不是 N 的寄存器位数不够。

Integer-N PLL：从参考时钟到反馈分频

参考时钟经 R 分频进入 PFD；VCO 输出经 N 分频反馈。PFD 比较两个边沿，CP 把 UP/DN 脉冲转换为电流，环路滤波器产生 VCO 控制电压。

fPFD=fREFR,fOUT=NfREFR

如果芯片在 VCO 后还有 channel divider，数据手册可能分别给出 VCO 频率与 RF 输出频率。频率规划时不能把输出 divider 忽略，也不能把它误认为反馈 N-divider。

设计取舍：提高 fPFD 可以让整数-N 频率步进变细，但同时受到 PFD、CP、N-divider 最大频率、最小 N 和 spur 等约束。不能只看分辨率一个指标。

Fractional-N：每拍仍然整数，长期平均可以是小数

Fractional-N 并不是让硬件某一次“除以 60.25”。多模分频器每拍仍执行整数分频，例如 60 或 61；调制器安排这些值出现的比例，使长期平均分频比等于 60.25。

Navg=N+α,0≤α<1fOUT=N+αfPFD

例子：N + α = 60.25

6060606160606061

每 4 次分频的总和是 241，平均值为 241/4=60.25。上面是简单一阶累加器序列；实际高阶 DSM/MASH 会生成更复杂的多位序列。

分频值变化会让反馈边沿相对理想位置提前或滞后，形成相位误差。调制器的任务不是消灭每一拍的误差，而是让平均值正确，并控制误差随时间的分布。

NUM、DEN：小数目标如何编码？

芯片通常用整数部分 INT/N 和小数分子 NUM、分母 DEN 表示目标分频比。小数部分是有理数：

Navg=INT+NUMDENΔfstep=fPFDDEN

当 NUM 与 DEN 互质时，简单一阶分频序列通常要经过 DEN 个参考周期才回到相同累加器状态。若两者有公因数，序列周期可能缩短。序列周期性是 fractional spur 的一个重要来源。

DEN 越大

固定 fPFD 时，理想频率网格越细。例如 100 MHz / 225 ≈ 2.98 Hz。

分辨率不等于准确度

寄存器步进很细，不代表参考源精度、VCO 校准误差、温漂、spur 和相噪也同样优秀。

命名因厂商而异：INT/FRAC/MOD、N/NUM/DEN、FCW 等都可能出现。读 RTL 或数据手册时先确认分子、模数、调制器输入和调制器时钟，不要只看信号名猜含义。

真实芯片：Fractional-N 的实际功能框图

按 TI LMX2594 数据手册的功能框图重绘信号关系。芯片内部集成 VCO、参考输入调理、PFD、CP、N 分频和 ΣΔ 调制器；环路滤波器按器件方案外接。

TI LMX2594

  • 10 MHz～15 GHz 输出范围。
  • 32-bit 可编程 fractional denominator。
  • Fractional 模式 PFD 最高 300 MHz；Integer 模式最高 400 MHz。
  • ΣΔ 调制器阶数可配置，最高四阶。
TI 数据手册

ADI ADF4159

  • 13 GHz fractional-N synthesizer。
  • 25-bit 固定模数，INT + FRAC/225。
  • 第三阶 fractional interpolator。
  • 支持 FMCW ramp、FSK/PSK 调制。
ADI 数据手册

看真实芯片时要同时追踪参考路径、反馈分频路径、ΣΔ 输入字段、调制器时钟、N-divider 控制接口，以及 VCO 后面是否还有 channel divider。只看寄存器 FRAC 字段，无法判断完整频率规划。

量化噪声、Fractional Spur 与 Integer-Boundary Spur

Fractional-N 的分频序列在时间上变化，等效为反馈相位误差。理想 ΔΣ 调制器可以把量化噪声整形成高通形状，使低频量化噪声降低、高频量化噪声增加；PLL 的闭环传递函数再决定噪声到达输出的程度。

NTFLz=1−z−1L

Fractional spur

分频序列短周期重复，或与 CP mismatch、divider delay 等非线性作用后，可能产生离散边带。

Integer-boundary spur

VCO 频率与整数倍 PFD 频率之间的拍频，靠近整数边界时可能落入环路带宽。

Reference spur

参考馈通、CP 脉冲、电源/地耦合等产生参考频率相关边带。它与 fractional spur 的成因不同。

重要判断：提高 DSM 阶数不保证所有频点 spur 都下降。调制器阶数、PFD 频率、环路带宽、分母、MASH seed、dither、CP 非线性和 VCO/PFD 拍频都会影响最终频谱。

ADI ADF4159 数据手册明确区分 fractional spur 与 integer-boundary spur；其高模数 ΣΔ 设计旨在把部分量化误差谱扩散为宽带噪声，但并不意味着所有 fractional-N 芯片都没有离散 spur。

设计指标：不要只看频率分辨率

指标描述常见测量/核对方式
Frequency step相邻可编程目标频率的间隔核对 fPFD、DEN、输出 divider 与寄存器公式
Phase noise载波附近随机相位扰动相噪分析仪，注明载波、offset、RBW、积分范围
Fractional spur与分数序列相关的离散边带频谱仪扫描不同 NUM/DEN 与 channel
Integer-boundary spur靠近整数倍 PFD 的拍频边带在整数边界两侧细扫频谱

频谱测试建议

  1. 先测整数模式基线。
  2. 固定 fPFD，扫 NUM/DEN。
  3. 在整数边界附近加密频点。
  4. 记录 carrier、spur offset、spur dBc 和 RBW。
  5. 切换 MASH order/seed/dither 后重复。

频率规划检查

  1. 确认 fREF、R、倍频和后分频路径。
  2. 计算 fPFD 和 Navg。
  3. 检查 N-divider 最小值与调制器阶数限制。
  4. 检查输出 divider、VCO tuning range。
  5. 确认锁定、校准和同步模式。
