频率与相位

周期信号的频率描述单位时间内的振荡次数；相位描述振荡过程中的位置。对于非恒定频率，必须使用瞬时频率定义。

f 为 Hz；φ 为连续展开的相位，单位 rad。

当频率为常数 f0 时：φ(t) = φ(0) + 2πf0t。固定频率对应线性增长的展开相位，而不是固定相位值。

这里的相位 φ(t) 是连续展开（unwrapped）相位。实际示波器上观察到的周期相位通常折叠到 0～360° 或 0～1 UI。

参考相位与反馈相位

锁相环比较参考时钟与反馈时钟的相位。定义相位误差 eφ(t)=φREF(t)−φFB(t)。由相位对时间的导数，可直接得到频率误差与相位误差变化率的关系。

因此，频率相等时，相位误差的变化率为零；相位误差本身可以为零，也可以是一个非零常数。只有存在频率差时，展开相位误差才会持续累积。

例如 REF = FB = 100 MHz，且 FB 的边沿始终晚 40 ps：两个时钟已经频率相等，但相位不一致。相位是否需要调整，取决于系统允许的目标相位偏差。

两条时钟的频率完全相同，但相位差固定为 1.44°，此时对相位误差的导数描述正确的是？

边沿时间差与相位角

相位角度依赖所选的周期基准。对于周期 T、频率 f 的信号，对应边沿时间差 Δt 可换算为相位角。

时钟相位通常按周期（cycles）归一化；数据链路中的 UI 通常指符号间隔，不应在未指定时钟基准时直接混用。

XOR 鉴相器为何能反映相位差

查看来源原图

XOR 鉴相器对两路数字方波逐时刻进行异或：输入电平不同则输出高。对于等频、50% 占空比的理想方波，XOR 输出平均占空比与一定范围内的相位差成正比。

单调区间内，Δφ 以 rad 表示；存在幅值方向模糊与周期性折叠。

XOR 输出只能表示相位差的大小与波形重叠关系，单凭占空比无法在所有相位范围中判断谁领先；因此捕获能力与线性范围受到限制。PFD 采用边沿顺序判定，将在第 3、6 章进一步介绍。

理想 50% 占空比的同频方波，相位相差 90° 时 XOR 高电平占空比为多少？

频率偏差如何积累成相位偏移

定义 FB 相对 REF 的频率误差 ε = (fFB−fREF)/fREF。ppm 为相对误差的百万分之一。

正 ε 表示 FB 更快，定义的 eφ=φREF−φFB 随时间减小。

当观察 N 个参考周期时，若初始相位对齐，展开相位误差约为 −2π·N·εppm·10−6。若记录第 N 个对应边沿的时间差，则应使用精确周期差：

例题：100 ppm，1000 个参考周期

100 MHz 的 REF，FB 比其快 100 ppm，经过 1000 个 REF 周期，连续相位差约为 −0.100 个参考周期；第 1000 个 FB 边沿较相应 REF 边沿提前约 0.9999 ns。

「展开相位差」与「对应边沿的时间差」的符号一致但计算方式不同；当频差较大或出现 cycle slip 时，不宜仅用折叠相位推断累计周期数。

频率与相位测量指标

频率偏差与相位时间误差并非同一类量。测试报告必须指定参考时间轴、对应边沿、采样时长以及统计处理方法。

指标定义 / 单位典型测量方式
Frequency Error相对目标频率的误差（Hz、ppm）频率计；在固定门控时间内统计输出周期，记录基准与门时间
Static Phase Offset稳态对应边沿时间差（ps、°）双通道示波器触发同步测量；消除通道间 skew
TIE实际边沿相对理想或恢复时基的时间误差（ps）高速示波器得到边沿时间戳，再对选定基准求差
Period Jitter逐周期实际周期偏离平均或参考周期（ps）统计相邻同极性边沿间隔
Cycle-to-Cycle Jitter相邻两个周期长度的差（ps）对周期序列做一阶差分

读图例题：相同 RMS 的不同波形

频偏产生逐渐增长的时间偏移；随机抖动产生围绕平均值的波动。两者即使短窗口的 RMS 数值相近，时间序列形状及物理原因仍不同。

TIE 具体定义取决于选用的参考时钟恢复规则；不同测试标准、趋势去除方式与 PLL 测量带宽会影响报告数值。
