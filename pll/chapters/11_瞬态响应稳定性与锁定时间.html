瞬态响应的对象与输入条件

PLL 的瞬态响应描述参考频率、分频比、使能状态或相位命令发生变化后，输出频率、输出相位和环路内部状态随时间变化的过程。瞬态分析必须说明输入变化类型、初始状态及最终判据。

相位阶跃与频率阶跃

输入变化数学表达典型响应
相位阶跃ΔφREF(t)=φ0u(t)频率可短暂变化以修正相位，最终频率回到原值
频率阶跃ΔfREF(t)=Δf·u(t)输出频率转到新的目标值，相位斜率随之改变
分频比阶跃N1→N2目标输出频率变化，初始反馈相位通常不连续对齐

相位裕量较小时，闭环峰化和时域振铃通常增大；相位裕量增加通常可降低峰化，但可能降低某些设计下的响应速度。相位裕量并非唯一稳定性指标，还应检查增益裕量、多个交越点、延迟和高阶极点。

相位裕量与阻尼比不是普适一一对应

对指定的二阶环路滤波器族，可以由开环模型求出 PM 与 ζ 的关系；改变滤波器阶数、零极点配置或延迟后，该关系会变化。TI 的 PLL 设计手册给出特定二阶滤波器条件下的对应表，例如 PM=45° 时 ζ 约为 0.777，不能把该数值套用到任意 PLL。

Lock Time 的定义与测量

Lock Time 是从规定的事件时刻到输出满足规定锁定判据并持续满足指定确认时间的间隔。它不是单一自然常数，必须同时报告频率容差、相位容差、观察窗口、输出节点和起始事件。

频率判据相对误差或绝对误差|fOUT−fTGT| < 1 kHz
相位判据相位误差窗口或相位稳定条件|eφ| < 0.1 UI

测量节点VCO、分频输出、缓冲时钟或外部 RF 端口芯片 RF 输出端

不同器件的 LOCK 引脚可能使用不同阈值、迟滞和窗口。数字 LOCK 状态是判据逻辑的输出，不一定与模拟环路首次进入容差带的时刻相同。

测量注意如果仅用频谱仪观察载波频率，无法直接得到瞬时相位误差；若用示波器测 TIE，则必须说明参考源、触发方式、记录长度和测量带宽。

大信号过程与 Cycle Slip

线性小信号模型假设相位误差处于鉴相器可近似线性工作的范围。频率跳变、分频比改变或初始相位差很大时，反馈相位可能在环路来得及修正前跨过一个或多个完整周期，产生 Cycle Slip。

相位误差跨越一个完整的 2π 周期可视为发生一次 cycle slip。应区分：

量含义
Wrapped phase error按鉴相器周期映射到有限相位区间的误差
Unwrapped phase error保留累计相位变化，可统计完整周期滑移
Frequency error两个时钟频率差，决定相位误差累积斜率

TI 的 PLL 设计资料指出，频率切换时的初始相位误差可能在环路纠正前累积；当环路带宽相对比较频率很低时，Cycle Slip 风险增加。资料中“约 1%”是经验判断，不是通用稳定性边界。

模型边界Cycle Slip 属于非线性、离散事件过程。只使用连续二阶传递函数不能正确预测滑移次数；应采用 PFD 事件模型或行为级瞬态仿真。

真实设计案例：理论锁定时间与实测值

TI《PLL Performance, Simulation, and Design》第 16 章给出了一组理论与实测锁定时间对照：在指定环路滤波器、频率跳变和 1 kHz 容差条件下，理论估算约 446 μs，实测约 449 μs。该案例还指出，更换介质吸收较大的电容后，测得锁定时间由 489 μs 增加到 578 μs。

该案例说明：理论与实测接近时，模型能够解释主要动态；出现差异时，应检查电容介质吸收、CP 输出摆幅、VCO 调谐范围、VCO 输入电容、PFD 离散采样等非理想因素。

预测：在自然频率保持不变时，阻尼比从 0.35 增加到 0.8，通常会怎样变化？

阻尼增大使指数包络衰减更快，标准二阶系统的超调下降。过大的阻尼可能使响应变慢，具体需结合自然频率与系统零极点。

理解核对

Q11-1：产品规格写“Lock Time < 100 μs”，但没有频率跳变量和锁定容差，规格是否完整？

Lock Time 随频率跳变、容差、锁定判据、环路配置和环境条件变化。没有测试条件，数值无法复现。

Q11-2：连续二阶模型预测没有 cycle slip，是否足以证明大频率跳变不会发生 cycle slip？

Cycle Slip 是相位周期跨越和离散鉴相行为，必须采用适当的大信号/事件模型或实测验证。
