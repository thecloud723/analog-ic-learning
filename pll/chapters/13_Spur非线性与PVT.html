Spur、非线性与 PVT

8 节

随机噪声与离散 Spur

PLL 输出频谱中的不理想分量通常分为连续噪声和离散杂散。连续噪声以功率谱密度描述，离散 Spur 以相对于载波的功率比描述。两者单位和测量方式不同。

Spur 的偏移频率通常与参考频率、PFD 频率、分频器周期、供电开关频率、时钟耦合频率或调制序列周期相关。定位时应先记录 Spur 相对载波的偏移，再与系统中已知周期频率对照。

现象频谱表现报告单位
相位噪声连续裙边，随 offset 变化dBc/Hz
Reference Spur载波两侧常见 ±fPFD 及谐波窄线dBc
Fractional Spur与分数序列、量化周期或非线性相关的离散线dBc
供电/串扰 Spur偏移与干扰源频率或其组合频率相关dBc

Reference Spur 的周期性激励

锁定状态下，PFD/CP 常保留窄的 Anti-Backlash 脉冲以避免死区。每个 PFD 周期出现的电流脉冲、开关馈通和电荷注入会在环路滤波器输出形成周期性扰动。VCO 将调谐电压扰动转换为频率调制，在载波两侧产生以 fPFD 为间隔的边带。

ADI AN143 指出，Anti-Backlash 脉冲会在 VCO 调谐线上产生 fPFD 及其谐波成分；由于这些频率通常高于环路带宽，反馈环路难以将其完全消除。

整数-N PLL 的参考杂散通常围绕输出载波按 PFD 频率间隔出现。实际杂散幅度还取决于环路阻抗、CP 脉冲形状、VCO 增益和耦合路径。

Reference Spur 与 Fractional Spur 的区别

Reference Spur 的主要周期通常与 fPFD 及其谐波相关；Fractional Spur 则与分数分频序列、ΣΔ 调制周期、量化误差相关。Fractional-N 的细节将在第 14、15 章展开。

非线性与供电耦合

小信号线性模型通常假设 CP 电流、VCO 增益和环路滤波器参数在工作点附近近似恒定。实际电路中，这些参数可能随调谐电压、输出频率、供电和温度变化。

PVT 漂移与校准裕量

工艺角、供电电压和温度会改变 VCO 的自由振荡频率、调谐增益、偏置电流、谐振腔 Q、延迟单元速度以及 CP 电流。校准通常用于将振荡器工作点放入可跟踪的调谐范围，闭环跟踪则补偿运行过程中的剩余偏差。

其中 αV、αT 为在指定工作点附近测得的归一化灵敏度。工艺变化一般需要用 Process Corner 或 Monte Carlo 统计表示，不能简单作为连续温度/电压系数处理。

对可调谐 VCO/DCO，应检查目标频率在所有角落下是否落入可调范围，并保留足够的上下调节余量。仅在典型角锁定成功不足以证明 PVT 全覆盖。

理解核对

Q13-1：频谱仪测得一根 −65 dBc 的窄线，能否直接称为 −65 dBc/Hz 的相位噪声？

离散 Spur 是积分线功率相对载波的 dBc；相位噪声是单位带宽功率密度 dBc/Hz。

Q13-2：VCO 的 KVCO 随 VTUNE 改变，意味着相同的调谐电压纹波在所有频点产生相同频偏吗？

KVCO 是工作点附近的局部斜率 df/dV。不同工作点的增益不同，相同电压纹波会产生不同频率调制。
