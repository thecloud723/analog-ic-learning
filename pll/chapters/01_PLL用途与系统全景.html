PLL 的用途与系统全景

本章 8 节

PLL 的作用

自由振荡器的频率受工艺、电源电压、温度及负载影响。PLL 以稳定参考信号为基准，通过相位反馈调节振荡器频率，实现频率合成和相位同步。

自由振荡器（Free-running Oscillator）输出频率由器件与电路参数决定。温度、电源、工艺和负载变化会改变振荡频率；没有参考反馈时，频率误差会转化为持续累积的相位漂移。
锁相环（Phase-Locked Loop）持续比较参考与反馈相位，根据误差调整振荡器频率。锁定后，频率比由分频关系确定，相位差保持稳定。
闭环控制原理：PLL 通过调节振荡器瞬时频率改变输出相位，使反馈相位与参考相位之间的误差趋于稳定。

PLL 常见用途

频率合成由稳定参考产生一个或多个高频时钟/本振。
时钟清理与同步在指定环路带宽内跟踪参考、抑制部分振荡器扰动。
时钟/数据恢复在相关架构中恢复与数据时序同步的采样时钟。

电荷泵锁相环（CP-PLL）

CP-PLL 采用鉴频鉴相器（PFD）产生 UP/DOWN 脉冲，电荷泵将脉冲转换为充放电电流，环路滤波器产生 VCO 控制电压，输出经分频后反馈至 PFD。

PLL 规格、设计参数与测量

PLL 性能评价涉及系统规格、设计参数和测量结果。系统规格规定性能要求；设计参数决定电路与环路特性；测量结果用于评价是否满足规格。

System Specification · 系统规格设计必须达到的目标或边界，例如输出频率范围、Jitter 上限、Spur 上限、Lock Time 上限。
Design Parameter · 设计参数设计者可调整的量，例如 ICP、KVCO、滤波器 R/C、环路带宽、分频架构。
Measurement Result · 测量结果在明确条件下实测得到的数值，例如 82 fs RMS、−58 dBc Spur、12 µs Lock Time。
同一物理量可能具有不同属性。例如环路带宽既可以作为设计目标，也可以作为仿真或实测结果。报告中应注明目标值、设置值和实测值。

测试项目与测量仪器

频率 / 频率误差

频率计或频谱仪；报告常见 fOUT、ppm error、随温度/电源变化的曲线。

Phase Noise

相位噪声分析仪；横轴通常是载波偏移频率（Hz），纵轴为 dBc/Hz。

Spur

频谱仪；离散谱线相对载波的幅度通常以 dBc 表示，不是 dBc/Hz。

Jitter / TIE / Duty

高带宽示波器；要明确时钟恢复基准、测量带宽、统计长度和阈值。

Lock Time

示波器/时间相关测量；必须定义起点、频率/相位 guard band 和持续保持时间。

环路带宽 / Phase Margin

小信号模型、仿真或环路响应测量；要说明是开环交越还是闭环 −3 dB 带宽。

本章理解核对

Q1. 基本整数-N PLL 锁定时，鉴相器反馈端的频率应当是多少？
Q2. 若两个时钟同频，但反馈边沿始终晚 40 ps，能否说频率已经相等？
Q3. “Reference Spur = −60 dBc”和“Phase Noise = −120 dBc/Hz”可以直接比较哪个更大吗？
本章小结：整数-N PLL 的稳态频率满足 fOUT=NfREF；反馈环路通过控制振荡器频率调节相位。性能评价应结合频率、抖动、噪声、杂散及测量条件。
