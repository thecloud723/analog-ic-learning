# PLL 章节页面模板

以第 01 章《用途与系统全景》的实际页面为样板。新章节从该页复用外壳，再替换章节标题、页签和教学内容。

| 区域 | 统一要求 |
| --- | --- |
| 左侧 | PLL 课程目录，按主题分组，完整列出 01–18 章，标记当前章。窄屏通过目录按钮打开。 |
| 顶部 | 章号和章标题，下方放本章的小节页签，当前页签高亮。 |
| 正文 | 一次显示一个小节。先讲现象和基本概念，再给图、公式及读图提示。有交互时先让读者预测，再调参数核对。 |
| 底部 | 正文之后放一组翻页控件。左边白底描边「← 上一页」，中间「当前页 / 总页数」，右边蓝底白字「下一页 →」。边界状态沿用第 01 章的禁用样式。 |
| 图片 | 来源图使用本地相对路径并标注图号和来源。实测图、教学示意图和实时生成的实验曲线在图注里明确标识。 |

## 翻页验收

- 切换页签或按翻页按钮时，正文、页签高亮和页码同步。
- 左侧目录可以直接跨章。翻到章首或章末时，底栏按钮标明相邻章号。全课程首页和末页对应方向的按钮禁用。
- 桌面和窄屏都保持「上一页／页码／下一页」的顺序，每屏只有一组章内翻页按钮。

18 章共用 `assets/chapter-pager.css`，各章的页签逻辑负责同步正文、页码与边界按钮。

## 左侧章节目录

章名、顺序和相对链接取自 `pll/README.md` 的章节表。修改章节表或分组后，从仓库根目录运行 `python3 pll/sync_sidebar.py`，将目录写入全部章节 HTML。每章直接显示内嵌目录，离线打开时也能跨章跳转。
