## 页面规范

- 每章独立 HTML，支持离线运行。
- 左侧专题章节目录、顶部页签、底部上一页/下一页。
- 标准数学排版；正文、题目、图注和动态结果的上下标一致。
- 基础原理图 + 真实论文/工业产品图 + 测试图。
- 交互实验先预测、再操作、最后显示物理解释。
- 真实数据与教学仿真数据明确区分。
