## 1. 产品目标、范围和非目标

### 1.1 产品目标

把当前 A 部分 6 个以文章、原图和单个滑块为主的页面，升级为 6 堂可操作的 Classroom 风格小课。读者不是只阅读解释，而是需要在页面中完成：

- 预测一个现象；
- 操作一个有明确物理意义的实验；
- 观察至少一种动态结构（框图、时序、波形或曲线）；
- 读取定量结果；
- 将观察结果与公式和物理因果关系对应；
- 完成一个新条件下的检查题。

### 1.2 目标读者

- 已掌握数字逻辑、时钟、触发器和基本波形。
- 对模拟电路、PLL 和频域指标没有系统经验。
- 希望理解系统信号流、边沿关系、相位/频率关系和真实性能曲线。
- 不要求读者一开始就会控制理论或晶体管级电路设计。

### 1.3 本期范围

本期只改造以下 6 个既有页面，保留 URL 和导航关系：

| A1.1 | 整机由哪些模块组成 | A-INT-01 | 可点击 PLL 框图 + Guided Tour + 频率链计算 |
| A1.2 | 锁之前与锁之后 | A-INT-02 | 虚拟示波器 + 同步多曲线 + 时间游标 |
| A1.3 | 第一张相噪图怎么读 | A-INT-03 | 原始测量图读图 + 离散测量点游标 |
| A2.1 | 时间差怎样变成相位差 | A-INT-04 | 双时钟边沿操作 + 相位圆盘/数值读数 |

### 1.4 非目标

本期明确不做：

1. 不改造 B–F 页面，不改 SerDes。
2. 不重新设计 PLL 全站导航、侧边栏和翻页系统。
3. 不在 A 部分实现完整 CP-PLL、非线性捕获、Cycle Slip 或 Lock Detect。

6. 不复制 Classroom 的品牌、素材或源码；只借鉴 Guided Tour、可操作图、同步视图、即时反馈和实验任务的教学模式。
7. 不为每页创建一套互不兼容的 UI、画图和状态管理代码。
8. 不因本期设计而更改 L1–L4 的既有定义。

## 2. 教学体验总规范

### 2.1 每堂课的固定学习流程

每页必须按以下流程组织。可根据知识点调整模块高度，但不能省略“预测—操作—观察—解释—验证”的闭环。

1. **Learn：本页要解决的问题。** 一句话说明学习目标和预计用时。
2. **Predict：先预测。** 在显示关键实验结果之前提出一个具体问题，允许读者先选择判断。
3. **Explore：操作实验台。** 给出参数、结构、信号或曲线，默认值一打开就有结果。
4. **Observe：观察结果。** 自动更新相关视图、数值和状态说明；不要求读者自己从一堆图里猜。
5. **Explain：解释原因。** 将当前实验状态与公式、物理过程、适用条件连接起来。
6. **Check：换条件验证。** 给一个不同于默认值的新条件，读者预测后再运行并检查。
7. **Sources：追溯来源。** 公式、原图、实测数据和模型假设可以追到来源。

### 2.2 Classroom 风格的页面布局

桌面端默认采用三栏实验台，不是“正文 + 一个滑块 + 一张图”的文章布局：

- **左栏：任务与控制区**（建议宽度 240–280 px）
  - 本页目标、步骤导航、预测问题；
  - 参数输入、预设工况、播放/单步/复位；
  - 当前实验步骤和提示。
- **中栏：主实验区**（自适应，占主要宽度）
  - 交互式框图、时序图、示波器或曲线；
  - 主要图形必须有足够面积，不能缩成装饰性小图；
  - 选中对象、时间游标和步骤高亮要明显。
- **右栏：观察与解释区**（建议宽度 240–280 px）
  - 实时读数、单位、状态；
  - 当前步骤的“看这里”提示；
  - 关键公式和物理解释；
  - 当前模型/数据证据标签。
- **底部：验证区**
  - 预测题、检查题、提示和正确解释；
  - 下一堂课入口。

移动端改为单列：目标/预测 → 主实验图 → 控制 → 读数/解释 → 检查题。不能要求横向滚动整张实验台。

### 2.3 交互行为规范

- 页面首次打开必须有默认工况和可见结果，不允许空白实验框。
- 每个参数必须显示名称、当前值、单位和可调范围；重要参数提供合理预设。
- 滑块旁必须有精确数值；需要精确输入的参数同时提供数字输入框或步进按钮。
- Reset 恢复本页定义的默认状态；不能只把滑块复位而遗漏曲线/游标/步骤状态。
- Play/Pause/Step/Restart 只在存在时间或事件序列的页面提供，不要装饰性添加。
- 多张图共享同一状态和时间游标；禁止每张图独立使用不同的参数或时间轴。
- 每次操作都应有可解释的因果反馈，不只更新数字。
- 提供“为什么？”提示，解释变化方向；不能只有绿/红状态灯。
- 不以颜色作为唯一语义；曲线还需有图例、线型或文字标识。
- 动画必须支持暂停；遵循系统减少动态效果设置。
- 操作反馈应即时完成；A 部分 L1 计算在本地浏览器完成，不依赖网络。

### 2.4 每页至少有一个明确的实验任务

| 页面 | 读者必须完成的任务 |
|---|---|
| A1.1 | 在框图中指出参考路径、反馈路径、相位比较位置和改变振荡器频率的位置 |
| A1.2 | 根据初始频差判断 VCTRL、输出频差和相位误差的变化方向，再播放并验证 |
| A1.3 | 在真实相噪图中找到指定 offset，读出 dBc/Hz，并区分连续噪声与离散 Spur |
| A2.1 | 给定频率和时间偏移，算出相位差；改变频率后观察同一时间差对应的相位变化 |
| A2.2 | 给定频差和观察时间，预测相位累积圈数；区分模相位跳变与真实累计相位 |
| A2.3 | 通过逐事件操作，预测 REF/FB 谁领先、UP/DN 哪个脉冲产生，以及 VCO 应加速还是减速 |

## 4. A1.1 详细设计：整机由哪些模块组成

### 4.1 学习目标

读者完成本课后能够：

- 沿着参考路径走到 PFD；
- 沿着反馈路径从 VCO 回到 PFD；
- 解释 PFD 为什么比较参考与反馈；
- 区分 VCO 内部频率和经过输出分频后的 RF/Clock 输出频率；
- 知道反馈分频 N 和输出分频 D 不是同一个东西。

### 4.2 实验范式

**主实验：可点击 PLL 框图 + Guided Tour + 频率链计算器。**

主视觉采用教学用 SVG 框图，而不是只放一张不可操作的静态图片。JKU Fig. 74 原图仍需展示或在图旁直接链接，作为原始教材参照；教学 SVG 必须标注“依据 JKU Fig. 74 教学重绘”。

### 4.3 框图节点

至少包含以下节点和连接：

1. Reference / OSC。
2. Reference Divider R（可选显示）。
3. PFD / PD。
4. Charge Pump。
5. Loop Filter。
6. VCO。
7. Feedback Divider N（VCO 到 PFD 的反馈路径）。
8. Output Divider D（VCO 到 RF/Clock 输出的输出路径）。
9. RF/Clock Output。

交互要求：

- 点击节点：右侧显示模块作用、输入、输出、典型单位和本课程后续深入页面。
- 点击连线：高亮信号方向，显示当前信号的名称和频率关系。
- 点击“参考路径”：从 OSC 高亮到 PFD。
- 点击“反馈路径”：从 VCO 经 N Divider 回到 PFD。
- 点击“控制路径”：从 PFD 经 CP/Filter 到 VCO。
- 点击“输出路径”：从 VCO 经 D Divider 到最终输出。
- Guided Tour 至少 5 步：参考输入 → 相位比较 → 纠偏控制 → 振荡器 → 分频反馈闭环。
- 每一步都应高亮当前模块和相关连线，并在解释区说明“为什么需要它”。

### 4.4 频率链计算器

默认使用**通用教学 PLL**，不要把通用公式误写成某一芯片的寄存器约束。

公式：

- fPFD = fREF / R
- fVCO = N × fPFD
- fOUT = fVCO / D

默认参数：

| 参数 | 默认值 |
|---|---:|
| fREF | 40 MHz |
| R | 1 |
| N | 125 |
| D | 2 |
| fPFD | 40 MHz |
| fVCO | 5 GHz |
| fOUT | 2.5 GHz |

交互：
- 改 R、N、D，频率链各节点数值实时更新。
- 在 SVG 对应节点下方显示频率值。
- 点击“只看 VCO”或“只看最终输出”，突出不同频率节点。
- 显示 fVCO 和 fOUT 的区别提示。
- 对超出教学控件范围的值进行输入校验。
- 这里不做真实芯片合法性判断；参数范围只为教学计算服务。

### 4.5 芯片框图对照

保留 ADF4351 数据手册 Fig. 1 原图作为产品级对照。要求：

- 与通用教学框图分开显示，不能把通用参数计算结果直接贴到 ADF4351 原图上。
- 用标注/图例帮助读者在 ADF4351 原图中找到参考输入、PFD、CP、VCO、反馈分频和 RF 输出分频。
- 明确告诉读者：实际器件还有参考分频、Prescaler、INT/FRAC/MOD、输出 mux 等细节，后续 B1.2 才完整分析。
- ADF4351 的实际频率范围、寄存器约束和合法性检查不在 A1.1 实现。

### 4.6 A1.1 验收

- 默认计算必须得到 fPFD=40 MHz、fVCO=5 GHz、fOUT=2.5 GHz。
- 修改 N 后，VCO 频率变化，反馈分频后频率仍回到 PFD 频率（锁定关系）。
- 修改 D 只改变输出频率，不改变反馈比较路径中的 N。
- 每个节点可点击；每条关键路径可高亮；Guided Tour 可完整前进、后退和退出。
- 页面明确区分通用教学框图与 ADF4351 产品框图。

## 5. A1.2 详细设计：锁之前与锁之后

### 5.1 学习目标

让读者看到一个小频率偏差如何在闭环作用下逐渐减小，并理解：

- 频率误差、控制电压偏差和相位误差是三个不同量；
- 它们有不同单位，但在闭环中相互关联；
- 频率误差趋近零时，相位误差也会逐渐稳定；
- 这只是近锁点小信号模型，不代表完整捕获过程。

### 5.2 实验范式

**主实验：虚拟示波器（Oscilloscope）+ 三条同步曲线 + 时间游标。**

视图至少包括：

1. 输出频率误差 ΔfVCO(t)，单位 kHz。
2. 控制电压相对锁定点的偏差 ΔVCTRL(t)，单位 mV。
3. 参考减反馈相位误差 Δφe(t)，单位 mrad。
4. 时间游标位置的 REF/FB 边沿局部放大视图（只用于观察当前相位关系，不绘制整个 10 μs 内所有 100 MHz 边沿）。

三条曲线共用横轴和时间游标。读者移动游标时，三个读数和边沿放大视图同步更新。

### 5.3 模型定义

证据标签：**L1 / Linearized Type-II Behavioral Model**。

默认模型参数：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 初始 VCO 频率误差 Δf0 | −100 kHz | 相对锁定频率 |
| 自然频率 fn | 90 kHz | 教学二阶模型参数 |
| 阻尼系数 ζ | 0.7 | 欠阻尼 |
| 反馈分频 N | 125 | 相位误差按反馈路径换算 |
| VCO 增益 Kvco | 100 MHz/V | 小信号局部增益 |
| 初始相位误差 | 0 | 只注入初始频差 |
| 时间窗口 | 0–10 μs | 供教学观察 |

公式：

- ωn = 2π fn
- ωd = ωn √(1−ζ²)
- α = ζ ωn
- ΔfVCO(t) = Δf0 exp(−αt)[cos(ωd t) − (α/ωd)sin(ωd t)]
- ΔVCTRL(t) = ΔfVCO(t) / Kvco
- Δφe(t) = φREF(t) − φFB(t) = −(2π/N)∫₀ᵗ ΔfVCO(τ)dτ
- 对上述初始条件，Δφe(t) = −[2π Δf0/(N ωd)] exp(−αt)sin(ωd t)。

单位实现要求：
- 模型内部统一使用 Hz、s、rad、V。
- UI 可显示 kHz、μs、mrad、mV，但只在格式化层换算。
- 不允许把 mrad 的数值当 rad 参与后续计算。

### 5.4 操作与反馈

控件：
- 初始频差：−200～+200 kHz，默认 −100 kHz。
- 预设工况：VCO 偏慢、正好、VCO 偏快。
- Play / Pause / Step / Restart。
- 时间游标：0～10 μs。
- 可选视图：三条曲线叠放/单图放大；不得把不同单位曲线强行放在同一纵轴。

播放行为：
- 播放只推进时间游标，不重复运行数值求解器。
- Step 按固定时间增量移动游标。
- Restart 将游标和参数恢复默认值。
- 参数改变后立即重算全部曲线，并把游标回到 0。
- 曲线游标处显示数值，三条曲线的时间位置完全一致。

### 5.5 解释区必须显示

- ΔfVCO < 0：振荡器当前偏慢；在本模型的正 Kvco 假设下，VCTRL 相对锁定值为负。
- ΔfVCO > 0：振荡器当前偏快；VCTRL 相对锁定值为正。
- 频率误差是相位误差的变化率来源；不能把某一时刻的频率误差直接叫相位误差。
- 锁定后频率差可以接近零，但相位误差不必等于绝对零；模型的最终相位状态由环路类型和初始条件决定。

### 5.6 模型边界

必须在实验台固定位置显示：

> 本实验是理想二阶 Type-II 近锁点行为模型，用于理解频率误差、VCTRL 和相位误差的动态关系。它不包含 PFD/CP 脉冲、CP mismatch、VCO 饱和、捕获范围、Cycle Slip、器件噪声和真实芯片 Lock Detect。完整逐边沿实验见 C2 / LOOP-01。

第一版不依赖 LOOP-01 数据。后续如接入 LOOP-01 回放，必须作为独立 L2 数据层显示，并提供对应参数、数据集 ID 和工况；不能用 L1 曲线替代 L2 数据。

### 5.7 A1.2 验收

- 默认 Δf0=−100 kHz 时，t=0 的频率误差为 −100 kHz。
- 默认 Kvco=100 MHz/V 时，t=0 的 VCTRL 偏差为 −1 mV。
- t=10 μs 时，默认模型的频率误差约为 −0.271 kHz（显示精度允许 ±0.01 kHz）。
- t=10 μs 时，VCTRL 偏差约为 −0.00271 mV（显示精度允许 ±0.0001 mV）。
- 三张图游标同步；Play/Pause/Step/Restart 行为正确。
- 将初始频差改为 +100 kHz，三条曲线的方向应按模型符号正确翻转。
- 页面和数据导出中明确标记 L1 行为模型，不出现 SPICE/实测字样。

## 7. A2.1 详细设计：时间差怎样变成相位差

### 7.1 学习目标

让读者从两路同频时钟的边沿位置，理解时间偏移占周期的比例就是相位角占 360° 的比例。

### 7.2 实验范式

**主实验：双时钟边沿操作 + 相位圆盘 + 计算器。**

主图至少包括：
- REF 和 FB 两路方波/上升沿；
- 可拖动的 FB 上升沿；
- Δt 的水平标注；
- 周期 T 的标注；
- 0～360° 相位圆盘或相位指针；
- 右侧实时显示 T、Δt、Δt/T、Δφ（degree 和 rad）。

### 7.3 符号约定

本课程统一定义：

- Δt = tFB − tREF：反馈边沿相对参考边沿的时间偏移。
- Δφ = φREF − φFB：参考相位减反馈相位。
- 同频且 FB 边沿晚于 REF 时，Δt > 0，因此 Δφ > 0，即参考领先。
- 公式：Δφ = 360° × Δt/T = 360° × f × Δt。
- 弧度：Δφrad = 2π f Δt。

### 7.4 参数与默认值

| 参数 | 默认值 | 范围 |
|---|---:|---:|
| 时钟频率 f | 100 MHz | 25 MHz–1 GHz |
| Δt | +40 ps | −T/2 至 +T/2 |
| T | 10 ns | 由 f 自动计算 |
| Δφ | +1.44° | 由 f、Δt 自动计算 |

### 7.5 操作与反馈

- 拖动 FB 边沿时，时序图、相位圆盘、Δt 和 Δφ 同步更新。
- 改变 f 时，周期 T 自动变化；如果保持 Δt 不变，相位角随频率变化。
- 提供模式切换：
  - 固定时间差：改变频率，观察相位角变化；
  - 固定相位角：改变频率，观察对应时间差变化。
- 默认展示 100 MHz、40 ps、1.44°。
- 正负号必须与页面文字和图形一致。
- 不把“模相位的 ±180° 边界”讲成真实时钟边沿跳变；若展示回卷，要明确是相位表示方式。

### 7.6 A2.1 验收

- 100 MHz、40 ps 得到 1.44°。
- 200 MHz、40 ps 得到 2.88°。
- 100 MHz、−40 ps 得到 −1.44°。
- 固定相位模式下，频率翻倍，所需时间差减半。
- 边沿拖动、数值、圆盘和公式结果同步。

## 8. A2.2 详细设计：频差怎样积成相位差

### 8.1 学习目标

让读者理解：固定的时间偏移与持续存在的频率差不同。只要频率差不为零，相位差就会随时间累积。

### 8.2 实验范式

**主实验：相位累积器 + 未包裹相位/模相位双曲线 + 时间游标。**

主图：
- 上方：未包裹相位差（单位 cycle 或 rad，页面需固定一种主单位）。
- 下方或叠加第二轨：模 1 cycle 相位（−0.5～+0.5 cycle）。
- 右侧：当前 Δf、时间、初始相位、累计相位、模相位。
- 可选小相位圆盘：显示当前模相位角。

### 8.3 模型与公式

统一定义：

- Δf = fREF − fFB。
- φe(t) = φe(0) + 2π∫₀ᵗ Δf(τ)dτ。
- 恒定频差时：phase_cycles(t) = phase_cycles(0) + Δf × t。
- wrapped_cycles = phase_cycles − floor(phase_cycles + 0.5)，范围为 [−0.5, +0.5)。

默认值：
- Δf = +2 kHz。
- 初始相位 +0.15 cycle。
- 观察时间 1 ms。
- 结束时未包裹相位 +2.15 cycles，模相位 +0.15 cycle。

### 8.4 操作与反馈

控件：
- Δf：−5 kHz 至 +5 kHz，步进 0.5 kHz，默认 +2 kHz。
- 初始相位：默认 +0.15 cycle，可在 −0.5 至 +0.5 cycle 调整。
- 观察时间：0–1 ms，默认 1 ms。
- Play / Pause / Step / Restart / 时间游标。

图形：
- 两条曲线必须共享时间轴。
- 未包裹相位连续，不允许因为显示范围而裁掉整圈信息。
- 模相位在 ±0.5 cycle 边界跳变；跳变处应断线或加边界标记，不能画出跨越整个纵轴的斜线。
- 时间游标同时给出未包裹相位和模相位。

解释：
- Δf=0：相位保持初始值，不继续累积。
- Δf>0：参考频率高于反馈频率，参考减反馈相位持续增大。
- Δf<0：相位持续减小。
- 模相位的回卷是坐标表示，不自动等于 PLL 捕获中的 Cycle Slip；Cycle Slip 的判断留到 C2。

### 8.5 A2.2 验收

- 默认结束值为 +2.15 cycles，模相位为 +0.15 cycle。
- Δf=0 时整条曲线保持初始相位。
- Δf 从 +2 kHz 改为 −2 kHz 后，未包裹相位斜率反向。
- 模相位在 ±0.5 cycle 处正确回卷且图线不错误跨接。
- 时间游标读数与公式计算一致。

## 9. A2.3 详细设计：PLL 第一次怎么纠偏

### 9.1 学习目标

让读者通过真实的事件先后关系理解 PFD 的 UP/DN 输出，并把它们连接到后续的 VCTRL/VCO 变化方向。

必须让读者理解两个层次：

1. **单次边沿比较**：只能说明本次谁领先，是相位领先/滞后。
2. **连续多个周期比较**：如果频率不同，领先/滞后会逐周期累积，PFD 因而也能体现频率差。

### 9.2 实验范式

**主实验：PFD 逐事件状态机 + 多周期频差实验。**

页面提供两个模式：

- 模式 A：单次相位差。读者拖动 REF/FB 两个边沿，逐步执行一次比较。
- 模式 B：连续频差。读者选择 REF/FB 频率，观察多个周期中边沿偏移如何积累、UP/DN 脉宽如何变化。

### 9.3 PFD 理想事件模型

状态输出：
- UP：REF 上升沿先到后置位。
- DN：FB 上升沿先到后置位。
- 当 UP、DN 同时为 1 后，经过 tRESET，两路清零。
- 本实验为理想化事件模型，不包含 DFF 的真实传播延迟、亚稳态、CP mismatch、dead zone 或电荷注入。

状态逻辑：
1. Idle：UP=0、DN=0。
2. REF edge：UP=1、DN 保持原状态。
3. FB edge：DN=1、UP 保持原状态。
4. UP=1 且 DN=1：进入 reset pending。
5. reset delay 到期：UP=0、DN=0，回到 Idle。

单次比较示例：
- tREF=0，tFB=+200 ps，tRESET=20 ps：
  - REF 先到；
  - UP 先拉高；
  - FB 到达后 UP、DN 同时为高 20 ps；
  - Reset 后两路清零；
  - UP 脉宽约 220 ps，DN 脉宽约 20 ps。
- tFB=−200 ps 时对称，DN 是长脉冲。
- 两边沿同时到达时，两路都产生 reset-delay 决定的最小脉冲（本模型不模拟真实 dead zone）。

### 9.4 模式 A：单次相位差操作

控件：
- REF 边沿固定在 0 ps。
- FB 边沿可在 −2 ns 至 +2 ns 范围拖动。
- Reset delay 默认 20 ps，可在 0–100 ps 调整。
- Step / Play / Pause / Restart。

显示：
- REF、FB、UP、DN、RESET 五条事件轨道。
- 当前事件名称和时间。
- 当前 PFD 状态。
- UP/DN 脉宽和谁领先。
- 事件步骤说明。

### 9.5 模式 B：多周期频差操作

默认：
- fREF=100 MHz。
- fFB=99.9 MHz。
- 初始相位对齐。
- 展示 8 个比较周期。
- Reset delay 默认 20 ps。

操作：
- 可切换 FB 频率略低、相等、略高三种预设。
- 可调整频差和周期数量。
- 每周期显示 REF/FB 边沿位置差。
- 显示 UP/DN 脉宽随周期的变化。
- 点击某一周期，展开该周期的局部事件时间轴。
- 对 100 MHz 与 99.9 MHz，FB 周期略长，FB 边沿逐周期落后，UP 脉冲总体逐周期加宽；反之 DN 方向相反。

显示约束：
- 全局时间轴和单周期局部放大视图分开，避免 10 ns 周期中的几十 ps 脉冲在全局图上不可见。
- 局部放大必须标明时间单位和放大倍数。
- 如为可视性对脉冲宽度做视觉放大，必须标记“示意比例”，不得让读者误以为图形宽度就是绝对比例。

### 9.6 从 UP/DN 到纠偏方向

显示一个定性的后续因果链，不在 A 部分伪造 CP/滤波器的定量结果：

- REF 领先 → UP → CP 净充电 → VCTRL 上升 → 正 Kvco 假设下 VCO 加速 → 后续 FB 边沿提前。
- FB 领先 → DN → CP 净放电 → VCTRL 下降 → 正 Kvco 假设下 VCO 减速 → 后续 FB 边沿延后。

明确提示：
- 本页只显示方向和因果关系，不给出虚构的 ΔVCTRL 或 Δf 数值。
- CP 电流、滤波电容、净电荷和 VCTRL 的定量关系在 C1.2 学习。
- PFD DFF、Reset 电路和实际 dead zone 在 C1.1 学习。

### 9.7 A2.3 验收

- REF 领先时，UP 长脉冲；FB 领先时，DN 长脉冲。
- 两边沿相同时，理想模型按 reset delay 产生最小脉冲。
- 单次模式和多周期模式的事件状态一致。
- 100 MHz / 99.9 MHz 时，FB 边沿逐周期落后，UP 脉宽总体增加。
- 100 MHz / 100.1 MHz 时，FB 边沿逐周期提前，DN 脉宽总体增加。
- Reset delay 改变后，UP/DN 重叠段和最小脉宽同步变化。
- 页面明确说明单次相位比较与多周期频率判断的区别。

- 不新增 React/Vue 等框架，不增加运行时 CDN 依赖；静态 GitHub Pages 和离线本地服务器均可运行。

### 11.4 模型函数接口建议

a-classroom-models.js 至少提供以下纯函数：

| 函数 | 输入 | 输出 |
|---|---|---|
| frequencyPlan() | fREF、R、N、D | fPFD、fVCO、fOUT |
| settlingResponse() | Δf0、fn、ζ、N、Kvco、time array | ΔfVCO、ΔVCTRL、Δφe 三组同步采样 |
| phaseFromTimeOffset() | f、Δt | T、phaseDeg、phaseRad |
| phaseFromFrequencyOffset() | Δf、initialPhase、time array | unwrappedPhase、wrappedPhase |
| buildPfdTrace() | REF edge times、FB edge times、reset delay | 事件列表、UP/DN/RESET 状态区间、脉宽 |

要求：
- 参数单位写在函数文档和变量名中，避免同名变量混用 Hz/kHz、s/μs、rad/mrad。
- 对无效输入（NaN、负频率、R=0、N≤0、D≤0、ζ 超出模型范围）显式报错或显示校验状态。

- 同一输入重复调用结果必须确定、可复现。

### 11.5 UI 状态建议

每堂课至少维护：
- parameters：当前参数；
- selectedStep：Guided Tour/事件步骤；
- playbackState：paused/playing；
- cursorTime：当前时间游标；
- viewMode：当前视图；
- predictionAnswer：预测题答案；
- checkpointAnswer：检查题答案；

参数变化后：
1. 校验参数；
2. 调用纯模型函数；
3. 更新全部依赖视图；
4. 更新右侧读数和解释；
5. 必要时重置播放游标；
6. 不得保留上一组参数的旧曲线。

## 12. 响应式、可访问性和性能

### 12.1 响应式

- 桌面宽屏：控制/任务栏 + 主实验区 + 读数解释栏。
- 中等宽度：控制栏在上方或左侧，主实验区优先占宽，解释区放下方。
- 手机：单列；图表高度适当缩小，但控件和数值不能挤压到不可读。
- SVG/Canvas 应根据容器尺寸重绘；不得把 820 px 固定宽度的 Canvas 缩成模糊图。
- 所有图表的单位、图例和关键数值在手机上仍可见。

### 12.2 可访问性

- 每个 input、button、select 有可读 label。
- SVG 节点可通过键盘聚焦和 Enter/Space 激活。
- 当前高亮状态除颜色外，还需有边框、标记或文字提示。
- Canvas 提供 aria-label 和相邻文字读数。
- 键盘可以完成参数调整、步骤切换和答题。
- 动画提供暂停；尊重 prefers-reduced-motion。
- 错误状态通过文本说明，不只改变颜色。

### 12.3 性能与离线

- A 部分所有 L1 计算在本地浏览器完成。
- 初次页面加载不应为实验请求远程 API。
- 不新增大型 JS 库。
- 参数变化到图表更新应保持即时响应；普通设备目标低于 100 ms。
- 动画建议 30–60 fps；非必要不持续后台运行。
- 页面离线打开时，图、公式、交互和翻页仍可用（外部来源链接除外）。
