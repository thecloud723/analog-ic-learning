# 阶段 4 · Fractional-N 与 ADPLL 验收

2026-11-19 从[阶段 3 验收](PLL_S3_ACCEPTANCE.md)进入阶段 4。DSM-01 已提供有限字长基准、RTL 和谱比较。分数分频闭环与 ADPLL 定点实验仍在建设。

## DSM-01 位宽、量化与时序

输入 NUM/DEN 先按最近整数（正半取上）映射到 W 位分子，报告实际使用的分数为 word/2^W。在固定整数分频 N 与 fPFD 时，平均命令为 N 加各阶输出的长期平均，步进为 fPFD/2^W。无抖动一阶状态的周期是 2^W/gcd(word, 2^W)。多阶极限环周期需分别观测。示例 NUM/DEN=1/8、W=12，word=512。

三段采用 W 位余量模回绕、W+1 位加法和单级注册输出。在每个有效拍内第二和第三段使用当拍前级的新余量。相同拍编号下 Y₂=c₁+Δc₂、Y₃=c₁+Δc₂+Δ²c₃，Δ=1−z⁻¹。Python 各有效拍另验等价的余量抵消式，例如 2^W·Y₃=word_eff−Δ³r₃。四位有符号输出覆盖组合进位可能范围，实际接入分频器时须保证 N 加命令始终为合法正分频值。

同步复位清余量与历史进位、加载 16 位 seed，0 映射为 1。无效拍不推进余量或 LFSR，输出有效位清零，旧数据保持。抖动是两个相邻 LFSR 位的差乘幅度，输入在 0 到 2^W−1 处限幅。靠近端点时限幅可能使有效均值偏移，验证以有效输入均值为基准，并同时报告量化后的目标。

[Icarus Verilog 首次净环境测试](https://github.com/thecloud723/analog-ic-learning/actions/runs/44433709802)在 W=4/12/24 各通过 4,096 个逐拍向量，共 **12,288** 拍。包括复位、有效空拍、正负输出、各级余量、输入端点、零 seed 与幅度变化。

## 命令频谱

在固定 seed 0xACE1 的 16,384 拍矩形窗，比较同一 1/8 输入。表中最大谱格单位为 command²/bin，DC 已移除。每种频谱的单边功率总和均用 Parseval 对照时域方差。

| 阶数 | 关闭抖动最大谱格 | 打开 1 LSB 抖动最大谱格 | 打开后 0–0.05 fₛ 带内功率 |
|---|---:|---:|---:|
| 一阶 | 0.031250 | 0.031250 | 0 |
| MASH 1-1 | 0.243784 | 0.093474 | 1.947×10⁻⁷ |
| MASH 1-1-1 | 0.759756 | 0.004165 | 7.592×10⁻⁶ |

MASH 1-1-1 的最大谱格在此窗口下降 **22.61 dB**，带内功率由基准 0 增到 7.592×10⁻⁶。有限窗口内 Y₃ 均值为 0.125061，差对应误差抵消边界项。该谱是数字分频命令，射频输出的 dBc 或 dBc/Hz 须经 PLL 边沿模型计算。另用 1001/4096、seed 0x1234、幅度 3 LSB 重跑。

运行入口位于 [DSM-01](../labs/DSM-01/)。下一批接入逐沿 Fractional-N 闭环并比较理想平均分频。ADPLL-01 的定点、量化及校准验收尚未开始。
