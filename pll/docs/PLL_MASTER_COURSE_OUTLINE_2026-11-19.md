## 0. 本次规划的结论

### 0.1 课程定位

面向具备数字电路基础、但模拟电路和 PLL 系统经验有限的工程师。目标不是把读者培养成完整的模拟 IC 设计专家，而是让读者能够：

1. 看懂 PLL 的系统框图，知道每个模块的输入、输出和作用。
2. 从参考时钟边沿开始，追踪 PFD、CP、Loop Filter、VCO、Divider 的完整反馈过程。
3. 理解频率误差、相位误差、时间误差之间的关系。
4. 看懂 VCO、环路滤波器、Bode、瞬态、相噪、Jitter、Spur 等真实图表。
5. 理解 Integer-N、Fractional-N、MASH 和 ADPLL 的数字控制路径。
6. 能阅读 ADF4351、LMX2594 等器件数据手册、评估板资料和论文测试结果。
7. 能区分公式估算、行为模型、SPICE/RTL 仿真和芯片实测，知道一个结论的证据强度。

## 1. 统一教学方法：每页都要让读者“看懂并验证”

### 1.1 每个知识页面的标准结构

每页按知识点选择内容，不机械地堆满所有模块，但至少应具备以下要素：

1. **本页问题**：用一句话说明本页要解决什么疑问。
2. **直观图示**：系统框图、电路原图、时序图或真实测试曲线。
3. **物理过程**：说明信号从哪里来、经过什么模块、发生什么变化。
4. **关键公式**：给出变量、单位、推导来源和适用条件。
5. **读图说明**：横轴、纵轴、单位、曲线特征、关键点和工程含义。
6. **交互实验**：让读者改变一个物理参数，观察对应的信号、曲线或指标变化。
7. **预测与验证**：先让读者判断变化方向，再拖动参数验证。
8. **模型边界**：明确未模拟的物理效应，以及结果是否来自真实仿真/实测。

### 1.2 交互的基本原则

每个交互都应体现完整因果链：

**修改参数 → 影响的模块/状态 → 物理量变化 → 图形变化 → 指标变化 → 工程解释。**

具体要求：

- 默认打开页面就能看到有意义的实验结果，不要求先拖滑块。
- 每个参数显示单位、默认值、范围和物理含义。
- 有典型工况预设，例如正常锁定、初始频偏、振铃、CP 失配、低 Q、Dither 开/关。
- 图表和指标由同一个模型状态驱动，不允许每张图各算一套数据。
- 支持 Reset；时域实验按需提供 Play/Pause/Restart/时间游标。
- 复杂页面提供 Overview、Timing、Bode、Spectrum、Jitter 等视图切换，不把所有图挤在一起。
- 普通 L1 交互目标是即时响应；复杂计算不应阻塞页面。超过约 10 秒的真实仿真转到 Notebook/任务运行，不伪装成普通滑块。

### 1.3 曲线教学的强制要求

本课程最大的教学重点之一是“读懂曲线”。因此所有重要曲线都要有配套的读图训练：

| 曲线 | 必须教会读者识别什么 | 推荐交互 |
|---|---|---|
| 时钟/边沿时序 | 周期、相位领先/滞后、时间差、UP/DN、复位延迟 | 拖动边沿偏移、切换频差、逐事件播放 |
| VCO 调谐曲线 | 横纵轴、工作区间、调谐范围、局部 Kvco、非线性 | 改变 L/C/码字/控制电压，显示工作点和切线 |
| VCTRL 瞬态 | 平均值、纹波、建立过程、饱和、稳态 | 改变 CP 电流、失配、R/C、初始频差 |
| Bode 图 | 增益交越、相位裕量、零极点、闭环带宽、峰化 | 改变 R/C、Icp、Kvco、分频比并同步显示指标 |
| 阶跃响应 | 上升、超调、振铃、稳定时间、稳态误差 | 切换阶跃幅度、阻尼和带宽 |
| Phase Noise | 载波、offset、dBc/Hz、噪声裙边、拐点、噪底 | 改变噪声源/Q/环路带宽，显示曲线与游标 |
| Spur Spectrum | 离散谱线位置、dBc、与噪声底的区别、RBW | 改变周期性激励、失配、泄漏、频率调制幅度 |
| Jitter | 积分频段、RMS、RJ/DJ、TIE、Peak-to-Peak | 改变积分上下限、载波、噪声源和记录长度 |
| Fractional/MASH 频谱 | 序列周期、命令谱、NTF、噪声整形和离散音调 | 改变分数、位宽、阶数、seed、Dither |
| TDC/DTC/DCO 曲线 | 量化台阶、LSB、INL/DNL、码字增益、饱和 | 改变分辨率、增益、偏置、校准参数 |

**实测曲线不能被“滑块改写”。** 对实测数据应保留原始测量点；交互可以改变游标、积分范围、对照模型和拟合方式，但必须清楚区分实测点与模型曲线。

### 1.4 每页统一的证据标签

- **Formula / Analytical**：解析公式或直接计算。
- **Behavioral Model**：教学行为模型或数值系统模型。
- **SPICE Simulation**：明确仿真器、PDK/模型、网表和工况。
- **RTL / Digital Simulation**：明确 RTL 版本、仿真器、位宽和时钟条件。
- **Measured**：真实器件/评估板测量，并记录仪器与工况。
- **Estimated**：数据手册、经验模型或拟合估算。
- **Not Available**：尚无可信证据。

同一页面可以同时包含多种证据，但必须逐条标注；不得把行为模型的 FFT 写成芯片实测相噪。

### D 部分必须统一的计量口径

- 相噪曲线：频偏是距载波的正频率，纵轴 dBc/Hz；离散 Spur 使用 dBc。
- 积分 Jitter：明确 SSB/单边 PSD 定义、积分上下限、载波频率、是否包含离散项。
- TIE、Period Jitter、Cycle-to-Cycle Jitter 是不同指标，不能互换。
- RJ 与 DJ 分开：RJ 用统计 RMS，DJ 按确定性波形/分布描述。
- FFT 必须记录采样率、记录长度、窗函数、ENBW、单双边、幅值/功率归一化。
- 实测数据点不足时，只能做局部拟合和留出误差报告，不得反推唯一噪声物理来源。

**D 部分核心实验：NOISE-01 + PLL-04。** NOISE-01 负责七源随机噪声、闭环传递、PSD 和积分 Jitter；PLL-04 负责周期性 CP 激励、Reference Spur 和示例积分。两者互补，不能合并成“一个完整 PNoise 仿真”。

### 建议新增的 F1.4（候选页，尚未纳入现有 52 页）

**PLL 上板测试与故障定位：从现象找到问题**

建议纳入以下内容：
- 无输出、频率不对、无法锁定：参考输入、寄存器、PFD、VCO 调谐范围和反馈路径的排查顺序。
- 锁定但相噪差：参考源、VCO、环路带宽、供电、布局和测量设置。
