## 洁净检出复跑

在仓库根目录运行 `node pll/labs/PLL-SPICE/run_loop01.mjs /tmp/loop01`。输出目录下每个 run_id 留存 `settings.json`、`events.csv`、`samples.csv` 和 `manifest.json`。使用 Node v24.22.3，干净检出源码 `a05c7bfed2d6ba658a5298bf8d3fb8c6bb9dd315`。

- 40 MHz 参考、N=125、目标 5 GHz、起始频差 −80 MHz。共同配置中的 CP=100 µA、R=4.7 kΩ、C=100 pF、下拉失配 5%、复位延时 0.5 ns。时窗 45 µs。
- 分段 VCO 曲线来自课程教学模型。0.2–1.6 V 为假设的控制范围。事件模型使用串联 RC，尚未纳入 SPICE 版本的并联小电容。当前运行属于行为级模型。
- 频差 ≤100 kHz、模相位误差 ≤0.05 圈且电容电压在两电源界限之间，须同时连续保持 4 µs。相位约定为参考圈数减反馈圈数，确认在每个参考周期的采样点进行。
- 1,801 个周期采样，5,400 条事件行，包含 1,801 次参考边沿、1,800 次反馈边沿和 1,799 次复位。事件可合并多个标记。

- 课程网页覆盖的 90 组模型输入，新旧运行采样值逐项完全相同。非法 N=0 在写出结果前会报错。

沿用同一模型配置，分别从共用 JSON 改初始频差、下拉失配和复位延迟。对事件流从 UP 与 DN 首次同时为高的时刻起计时，允许其间出现新参考边沿。延时非零时，复位必须在配置延时到期，容差为 0.1 fs。零延迟时，同一事件处理完毕后两路不得同时为高。

## 2026-11-19 串联 RC、SPICE 校准与捕获扫描

[净环境 GitHub Actions](https://github.com/thecloud723/analog-ic-learning/actions/runs/44405573563)跑通独立脉冲、PLL-01 SPICE 调谐提取、两组 VCO 模型、11 点捕获扫描和 PLL-03 对照。脉冲用 100 µA、4.7 kΩ、100 pF、0.5 ns 平顶与 1 ps 上下沿。四种净电荷分别为 +50.10、−50.10、0、+2.505 fC，覆盖 UP、DN、匹配重叠和 5% 失配重叠。ngspice 与解析串联 RC 对照的最差节点误差 **0.13 nV**，门限 2 µV。闭环基准的事件间电流积分与电容电荷变化最大残差 **1.12×10⁻²⁶ C**。脉冲验收限于未触发电源钳位的串联 RC。

同口径对比复用 PLL-03 的 **0.630199 V** 初始调谐控制电压和 35 µs 时窗。两者频差连续 4 µs 在 ±100 kHz 内的入带时刻分别为 **14.975 µs**（LOOP-01）和 **15.145 µs**（PLL-03）。末点差值为 **81.96 µV**、**0.000131 圈**和 **20.22 Hz**。PLL-03 的 CP 是从 PLL-02 提取的周期平均增益及偏置，LOOP-01 保留逐边沿复位与重叠脉冲。这项验收覆盖相同调谐与串联 RC，不将平均模型用于逐边沿波形的参考标准。

VCO 明细模式通过 `recordVcoEdges` 开启。在逐边沿模型的校准基准中，225,000 个 VCO 上升沿单调递增，每第 125 个与 1,800 个反馈边沿时间戳逐条一致。独立 PFD 用例暂时断开 CP，以验证解析的相位边沿时刻与复位延时。默认网页运行无需生成这一明细。
