# PLL 教材内容改造规范：原始资料优先（Source-First）

> 日期：2026-11-19  
> 状态：**内容策略已修正；现有六页交互代码保留，尚未实施此轮内容重排。**  
> 范围：当前先处理 PLL A1.1～A2.3，原则随后适用于 B～F；SerDes 暂不涉及。  
> 背景：2026-11-19 Work 已按 [PLL A Classroom SDD](PLL_A_CLASSROOM_SDD_2026-11-19.md) 实现六堂交互课，但用户确认实际目标并非“自己重写教材、重新绘图、重新写公式”，而是把 JKU、TI、ADI 等已有优质教程的资料按自定义学习路径摘选、中文整理并组合；交互作为辅助理解手段。

## 0. 核心决定

**教材内容由可信原始资料主导，交互工具为教材服务。**

1. 教程的章节顺序由本项目决定，不受原教材目录顺序约束。
2. 每个知识点首先搜索、阅读、定位可信原始教材的对应文字、图号、公式和测试数据。
3. **有合适原图时优先用原图，有合适原公式时使用原公式和符号定义；不为“风格统一”重画静态原理图或另造不必要的公式。**
4. 中文正文应忠实解释被选材料：对许可允许再利用的来源，可选取相关段落进行中文本地化/改编并注明改动；对限制复制的资料，使用简明中文摘要、必要的短引文和源文件链接，而非大篇幅译载或复制。
5. 保留 Classroom 这次开发的真实互动功能，但把已有交互实验放到对应图、公式之后或旁边，作为“动手验证原教材的结论”，而不是让自绘实验图替代原图。
6. 保留必要的**动态绘图**（如可拖动边沿、曲线、游标），但它们必须明确标注是“交互实验生成视图”；不得另外绘制一张功能重复的静态电路图并把原图挪到页末。
7. 数学符号、定义、单位应尽量采用主要来源的原始约定；如为了整套课程统一而改变符号或定义，必须在公式旁明确标注映射关系。
8. 对图、公式、译文、仿真结果分别建立可追溯来源，不仅在页末提供一个教材首页链接。
9. 此规范优先于旧 SDD 中关于**教材内容占比、图文呈现顺序、重新绘图**的要求；旧 SDD 的交互模型、已通过测试、组件结构和操作行为继续有效，除非与原始资料物理定义冲突。

## 1. 更正我们此前误解的需求

### 之前按旧 SDD 做成了什么

- 六页都有 Learn/Predict/Explore/Observe/Explain/Check。
- 很多主视觉是自定义 SVG/Canvas，独立实现公式和图表。
- 原始 JKU/TI/ADI 图像存在于部分页面，但大多放在实验台之后、作为来源或补充。
- A2.1 的原教材公式只以网页中简写公式及页尾参考链接出现；课堂演示的相位圆盘与时序图是我们自己的交互视图。

### 新目标

- **主体是经过筛选的高质量教材原内容**：原图、原公式、原始例子、原文的忠实中文解读，以及不同教材材料的重新编排。
- **辅助是交互实验**：读者看完图和公式，能直接操作参数验证其物理意义；可以并排显示，不能喧宾夺主。
- **附加是工程案例**：TI/ADI 产品框图、数据手册表格、真实测量和已有 SPICE/RTL 数据，只在能回答对应学习问题时加入。
- 课程的创新主要是**选择、编排、中文解释、跨教材关联、读图指引、交互和实验复现**，不是重新创作一套与原教材重复的理论内容。

## 2. 每个页面的标准结构（必须按这个顺序设计）

1. **学习问题与先修知识（简短）**：本页要回答什么、为什么放在这里。
2. **核心原教材材料（主视觉）**：展示原始图、公式或真实测试曲线，以及直接关联的出处；有多个来源时标记主来源和补充来源。
3. **中文内容整理**：忠实解释所选材料的逻辑、变量、物理意义和推导，尽量保留公式原来的表示；可在图中原有英文术语旁提供中文对应表，但不要改坏原图。
4. **原图/原公式怎么读**：指出图上哪个模块/坐标/箭头对应哪个变量；哪一步公式用到了哪一条物理关系。
5. **交互验证**：复用已实现的 Classroom 实验台，明确写出“这个实验正在验证原教材的哪个图或公式”，参数默认值优先匹配原文示例。
6. **读者核对与扩展**：一个与教材相关的任务，必要时有计算示例、错误理解和边界说明。
7. **来源/许可/版本记录**：文献名、章节、图号、公式号、原始地址、使用方式、许可证、是否经中文改编。

注意：有些页面没有合适的静态原图，可以让**原公式+中文解读**成为教材主体；动态曲线/时序仍作为实验，不需要为凑“原图数量”硬塞不相关图片。

### 2.1 页面 UI 的位置关系

**默认打开先看教材，实验按钮非常容易找到。**

推荐：
- 页面主区域宽屏中 60%～75% 空间优先留给原图、原公式和中文解读，随知识点调整。
- 可以用“教材 / 实验 / 原文”页签，但“教材”必须是默认视图；也可在同页直接并排，而不是把原图藏到页尾。
- 侧边栏保持原 52 页的导航。
- 保留现有互动控件、同步图和答题，必要时将实验移到教材图下方而非删掉。
- 同一原图只展示一次，避免正文和页尾重复。
- 每张图和每条关键公式下，直接放可点击的“JKU 7.1 Fig.74”“TI SNAU210B Fig.5-1”等来源，不使用无信息的“ref:”。
- 不能只把来源 URL 放在 Sources 小节，却让用户阅读时无法知道当前图/公式来自哪里。

### 3.1 A2.1 页面重排的具体例子

旧顺序：
- 自己提出预测题；
- 自绘时钟图与相位圆盘；
- 自己重新讲公式；
- 页尾给一个 JKU/ADI 参考地址。

**新顺序：**
1. 标题：时间差怎么转换成相位差？
2. 「来自 JKU §7.1 的原始公式」：展示原公式 **Δφ = 2πΔt/Tref**，旁边直接链接到 JKU 原文。
3. 中文说明：Δt 对应的边沿位置偏差，相对一个参考周期所占的比例就是一圈 2π 中的相应比例。明确符号约定，并解释 tFB 与 tREF 的先后关系。
4. 用课程数值例子：100 MHz → T=10 ns，Δt=40 ps → Δφ=0.02513 rad ≈1.44°。数值例子标为“本课程算例”，而非 JKU 原文算例。
5. 「验证这条公式」：嵌入 Work 已完成的双边沿拖动与相位圆盘；拖动 FB 边沿，公式右侧数值同步变化。
6. 问题：固定 40 ps 不变，频率翻倍，相位角为何也翻倍？
7. 原文来源、许可、内容改编说明。

**这一页无需另画一张静态相位时序图。** 原始公式+中文讲解是教材主体，已有动态边沿实验已足够。

## 4. 原资料整理方式：先有来源包，再编排页面

每页实施之前，必须先形成来源清单，而不是先写 HTML 再补参考文献。

每条资料按以下字段入库：

| 字段 | 说明 |
|---|---|
| source_id | 唯一原始资料 ID，例如 JKU-RFIC-7.1-F74 |
| source_title | 教材/文章/数据手册名称 |
| source_url | 精确到原网页章节或 PDF 页码的地址 |
| edition / revision | 文献版本、PDF Rev、检索/核对日期 |
| section / figure / equation | 原始章节、图号、公式号 |
| asset_path | 本地原图的真实路径；若因授权问题不能本地再发布，留源链接 |
| license / rights | 许可及第三方例外；允许怎样使用、是否需要署名 |
| content_type | 原图、原公式、原文节选、公开实测、教学推导 |
| chinese_adaptation | 中文整理/摘要/短译/术语表 |
| target_page | 对应的本课程页面 |
| teaching_reason | 为什么选择这段材料，它解决本页哪个问题 |
| interaction_link | 哪个交互验证它 |
| review_status | 已核实 / 待核实 / 不适合纳入 |

推荐文件：
- pll/docs/PLL_A_SOURCE_MAPPING_2026-11-19.md（或机器可读 JSON + Markdown 视图）
- pll/assets/originals/（已有本地原图优先复用）
- materials/pll/originals/（原始资料归档，仅依据原仓库目录约定维护）

资料整理要细到 **具体图、具体公式、具体论述**，而不是“参考 JKU 第 7 章”或“参考 TI 某 PDF”。

## 5. 版权与许可边界（必须核对）

**JKU RFIC：**
- JKU 公开课程和源码声明为 Apache-2.0，可作为主要原始教材来源，在遵守许可和署名条件的范围内进行改编/中文本地化。
- 具体图中若含第三方来源，应逐张检查原图标注与额外许可；不能因网页整体开源就假定第三方素材全部可自由再许可。
- 对 JKU 教材的改编要保留作者、机构、原始链接、许可和改动说明；保留必要的 LICENSE/NOTICE。

**TI/ADI：**
- 产品数据手册/应用笔记/评估板图不应默认视为开源可再发布素材。
- TI 的公开版权条款对直接镜像、再发布和改编有限制；若没有适用授权或许可，优先使用**可点击的官方原文链接、中文原创解释和少量必要引用**，不要把整张受限图复制到公开 Pages，更不要把整章全文翻译后公开发布。
- 已经入库并发布的 TI/ADI 原图需做一次单独权限审计。私人学习材料与公开 GitHub Pages 属于不同的分发情境。
- 公式作为数学事实可以保留其数学表达，但不要把来源的整页说明及布局不加辨别地照搬。
- 对含许可证限制的图像，若不适合本地分发，可用来源链接或经过授权的替代素材；不要因此自行编造一张无物理依据的原图。

可核对来源：
- JKU 项目与 Apache-2.0：https://github.com/iic-jku/radio-frequency-integrated-circuits
- TI Copyright：https://www.ti.com/legal/terms-conditions/copyright.html

## 6. 本轮 Work 任务实施方式

### Step 0：冻结已完成交互功能

- 以现有 A 部分六页为基础，不删除已完成的可用交互组件。
- 读取 [PLL A Classroom 验收报告](PLL_A_CLASSROOM_ACCEPTANCE_REPORT.md)、最新主分支以及模型测试。
- 明确本轮是**内容编排与教材源材料优先级的纠偏**，不是重做整套交互引擎。

### Step 1：逐页建立原始资料映射

- 对六个 A 页面逐页找出 JKU 对应章节、图号、公式号和原文核心论点。
- 补充 TI、ADI、数据手册来源；每条标明再利用许可。
- 检查现有已下载原图是否匹配最新原文，是否能够公开分发。
- 形成 [A_SOURCE_MAPPING] 清单后才能动 HTML。

### Step 2：先以 A2.1 做一页样板

- 原公式、原始上下文和简明中文解读出现在实验台之前。
- 保留现有交互的拖动、圆盘、数值和测试逻辑，但让它明确验证上述公式。
- 不增加新静态自绘图。
- 复核单位、符号、来源和浏览器布局。
- 完成后以这一页作为 A 其他五页内容优先的对照模板。

### Step 3：重排其余五页

- 每页按“原教材材料 → 中文解释 → 如何读图/读公式 → 交互验证 → 练习”的顺序。
- 优先只移动/补充内容，而非重写已经可用的模型或动画。
- 对 JKU 图严格按照 fig 编号对应的物理意义放入正确页面，不为凑数乱用图片。
- 对暂缺原图的页，先核对是源材料确实没有，还是还没纳入仓库，不要静默用新图代替。
- 中文描述可以加入数字工程师所需的先修知识，但要区分“原资料的内容”和“本课程补充解释”。

### Step 4：验收与提交

至少检查：
1. 六页每页都有清晰的主教材来源及本页对应的具体章节/公式/图号。
2. 如果原始图/公式可用且许可允许，正文直接显示，并能从图/公式旁打开来源。
3. 不再把关键原图藏在长篇交互之后或页尾。
4. 无重复静态重绘替代可用原图。
5. 中文说明忠实原文，没有偷换物理概念、符号或测试条件。
6. 交互实验正常运行，并明确指出验证哪条教材结论。
7. 数值、模型、移动端、离线等原有回归测试继续有效。
8. 所有可分发素材有许可记录；版权受限项给出合适替代/授权处理状态。
9. 更新 README、A SDD 的交互/内容分工、PROGRESS 和本文件状态。
10. 提交 GitHub commit，完整记录六页修改清单及验收证据。

**验收重点由“有几个新交互”转为“原教材内容是否真实成为课程主体，且交互是否有助于读者理解对应原图/原公式”。**

## 7. 不允许重复发生的错误

- 原教材已经有高质量 PLL 电路图，却另画一张更简化的静态框图作为唯一主视觉。
- 明明有 JKU 原始公式，却写一个无来源的自创等式取代。
- 只在页尾写一个链接，而没有把对应教材正文、图/公式真正组织进课程。
- 一页主要内容是预测题和实验控件，原教材被放在实验台后面的小栏里。
- 把 TI/ADI 数据手册内容按 JKU 的 Apache-2.0 处理。
- 把整章受版权保护的材料未经授权全文翻译并公开。
- 因为要“原图优先”就删掉 Work 已经实现且正常工作的交互实验。
- 未核对原教材就按已有 SDD 的某个简化叙述强行改动物理定义。

---

**最终交付形态：高质量原始教材的中文组织与解读，是教学主体；Classroom 交互实验是操作、验证和加深理解的工具；SPICE/RTL/实测是独立的深入证据层。**
