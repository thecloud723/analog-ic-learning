# 阶段 3 · NOISE-01 相位噪声和抖动验收

2026-11-19 从[阶段 2 验收](PLL_S2_ACCEPTANCE.md)进入阶段 3。当前完成分源模型、积分基准和时域统计首轮验证，公开实测曲线对照及网页实验仍在建设。

## 统一口径

- 频率 f 是距载波的正频偏，单位 Hz。内部使用单边相位 PSD Sφ，单位 rad²/Hz。小相位调制下，线性 SSB 相噪 L(f) = Sφ(f)/2。通带内相位方差为单边 Sφ 积分，等价于 2∫L(f)df。dBc/Hz 先转线性再积分。
- 随机时间抖动 RMS 用相位标准差除以 2πf₀。这是指定频带的积分相位抖动。TIE 是各边沿相对参考时刻的差，周期误差是相邻 TIE 差分，cycle-to-cycle 误差为相邻周期误差差分。须按定义和频带比较仪器读数。
- 离散纯 PM 使用单条对称边带的幅度。小调制指数下，边带功率比为 β²/4，对应确定性相位方差 β²/2。频带内多条不同频偏的正弦按足够长、相互正交的观察窗口合计；这些 dBc 条目与连续 PSD 分开。器件可能同时有 AM 和 PM，单根实测边带不能直接反推出 PM 抖动。
- 仪器的 RBW 与抖动积分上下限分别记录。默认 12 kHz–20 MHz 沿用 PLL-04 工况。接近 40 MHz PFD 的一半时，连续时间模型只提供趋势参考，采样和折叠效应需要离散模型验证。

## 源和传递

令 Z = 1/[sCp + 1/(R + 1/sC)]，A = 2πKvco/s，G = Icp·Z·A/(2πN)，S = 1/(1+G)，T = GS。Kvco 按 Hz/V，角相位按 rad。各源按独立随机过程建模，输出谱为各输入单边 PSD 乘传递幅度平方的线性和。参考与 VCO 传递沿用 [JKU 源与公式对照](PLL_S1_04_FORMULA_INDEX.md)。

| 源 | 输入单位 / 位置 | 传递 | 本基准的来源 |
|---|---|---|---|
| 参考 | rad²/Hz，在 PFD 参考口 | NT | 沿用 PLL-04 的教学斜率与底噪 |
| VCO 本征 | rad²/Hz，在 VCO 输出相位 | S | 沿用 PLL-04 的教学斜率与底噪 |
| 分频器/PFD | rad²/Hz，比较口等效相位 | −NT（反馈误差符号） | 假设白噪声 |
| 电荷泵 | A²/Hz，注入 VCTRL | ZAS | 假设白电流噪声，不含 PFD 等效相位噪声 |
| 滤波电阻 | V²/Hz，串联 R 的等效电压源 | ZAS/(R + 1/sC) | 300 K，单边热噪声 4kTR |
| 电源 | V²/Hz，在 VCO 供电节点 | (2πKpush/s)S | 假设 1 MHz/V pushing，未加 CP 共用供电通道 |
| 输出缓冲 | rad²/Hz，反馈取样点之后 | 1 | 假设白噪底 |

模型未把这些设定当作器件 PNoise 或实测值。独立源假设不适用于主要源经同一电源显著耦合的情况。

## 默认计算与验收

命令为 `python pll/labs/NOISE-01/noise01.py pll/labs/NOISE-01/noise01-settings.json NEW_OUTPUT_DIR`。输出按频偏列出线性单边 PSD、总 SSB 和各源功率增益，同时保存设置与摘要。

40 MHz、N=125、5 GHz、12 kHz–20 MHz 工况，七源随机抖动 **0.755425 ps RMS**。只启用参考与 VCO 时为 **0.197272 ps**，与既有 PLL-04 双源积分复算一致。单独的 1 MHz、−70 dBc 对称纯 PM 边带对应 **0.014235 ps RMS**。把这一正交确定性分量纳入长期 RMS，示例得到 **0.755560 ps RMS**。这三项采用同一载波和积分口径。

| 验收项 | 状态 |

在仅改变 ICP 50/100/200 µA 的敏感度扫描中，归一化参考传递的首次 −3 dB 下穿约为 245/360/551 kHz，随机 RMS 约为 1.339/0.755/0.464 ps。该对比固定了电荷泵电流噪声的假设密度，可用来观察环路增益影响，实际 CP 偏置改变也可能改变其噪声谱。
