## 核心内容规则

1. 先找原教材的**具体章节、图号、公式号、论述位置**，再排版 HTML。不能先自行重写教材、最后补来源链接。
2. 对许可允许的 JKU 原始内容，忠实中文翻译或整理，并在每个原图/原公式旁注明作者、原链接、许可和改动；逐图检查第三方例外。
3. TI/ADI 数据手册/原图不应默认具有公开再发布许可。权限不明确时，以官方直接链接、中文独立导读和必要短引文为主；既有公开本地图也要审计。
4. 不重复静态重绘 JKU 已有高质量图片，不重新创造有现成来源的数学公式。
5. **原教材及中文导读是阅读主体；交互只负责帮助理解它。** 不能再做成页面先出现预测题、巨大自绘实验台，原教材只剩页尾引用。
6. 数学排版必须是正常 LaTeX/MathML 风格：数学变量斜体、正体下标、上下标、希腊字母、单位；行内变量也一样。不得出现 fREF 这种伪公式、原始 HTML 实体或裸 LaTeX 字符串。
7. 保留 V1 已通过的全部关键交互；不得为重排内容而删除拖拽、圆盘、曲线、事件状态机、游标、Guided Tour、Reset、题目反馈。
8. 明确区别原作者公式/图、课程补充推导/例子、L1 行为模型、真实仿真、真实测量。
9. 不重构 B～F，不做 SerDes，不新增 SPICE/云端仿真。
