## 3. 页面排版必须以原教材内容为主体

### 3.1 新的内容顺序

六页统一遵循以下阅读顺序，按实际知识点适度增减：

1. **本页问题**：一句话说明要学会什么。
2. **原始教材核心材料**：合法可展示的原图和原公式，直接呈现；对受限图用准确的官方定位链接和必要的中文读图指南。
3. **中文解释**：介绍原图每一块、原式每个符号，以及它们之间的物理关系；逐段有条理地展开，不要只写一个口号。
4. **原图 / 原公式怎么读**：指出应看哪条线、什么坐标、哪一项、是什么单位。
5. **交互验证**：保留 Work 已完成的实验台，明确标记“验证 JKU 的哪条公式/哪张图”；可在正文紧邻处嵌入，而不是固定放最上方。
6. **工程对照（适用才有）**：TI/ADI 器件或测量与理论的对应和差异。
7. **读者检查题**：对原材料提出新条件，检测是否理解。
8. **来源与许可说明**：包含已在图旁呈现的精确来源索引，而不是代替图旁的链接。

不是每页都强行塞 Predict-first 流程。**旧 V1 的 Predict / Guided Tour 可以保留，但不应挡住原教材主体；预测题可移到原图与简短导读之后、实验开始之前。**

### 3.2 图像原则

- 必须优先搜集原作者图源（原网页、SVG、已有 PNG）和已有材料目录。
- 原图和“交互验证图”要有明确角色：
  - 原图：权威教材内容；
  - 动态 SVG/Canvas：演示、测量或验证原图结论；
  - 自绘静态图：只有源材料缺失、授权不允许且确有教学必要时，经明确记录才新增。
- 不为统一风格重新设计已有高质量 JKU 框图。
- 对复杂原图，尽量采用旁注、图号步骤、对照文字，避免破坏原图。
- 如果原图与动态交互必须同屏，可让原图成为主阅读视图，把交互放在紧邻的“验证实验”区，不必完全移除动态绘图。
- 媒体不能无意义地拉伸/裁切；必须在手机上可读，必要时支持点开大图。
- 不得把有“数据手册实测”的图重新绘成曲线然后称为“原始图”。

### 3.3 数学排版原则（强制）

用户明确不接受纯文本公式，例如 fREF（Hz）以普通字母堆叠、或 &#x66;REF 这样的 HTML 实体被当文本显示。

- 正文行内的变量也使用统一数学排版，不仅独立公式块使用。
- 一般数学变量使用数学斜体；表示对象/缩写的下标使用正体，例如 f_{\\mathrm{REF}}、f_{\\mathrm{VCO}}、T_{\\mathrm{ref}}、K_{\\mathrm{VCO}}。
- 希腊字母 Δ、φ、ω、ζ 使用标准数学形式；变量名称和单位严格区分。
- 正文不能出现未解码的 HTML 实体、被破坏的 MathML 或原始 LaTeX 源码。
- 交互中的动态数值使用统一量纲格式，但公式本体保持和原教材相同的符号体系。
- 优先复用仓库现有的 MathML/公式资源。不得为了换公式字体而要求外部 CDN；必要时采用已归档、具许可的本地渲染方案。
- 每条关键公式标明：原始公式，还是“由原始公式推导的本课程关系式”；不得伪造原始公式编号。
- 静态公式和动态计算模型的单位、正负号与精度必须互相对应。

## 4. 六页的逐页内容设计

### 4.1 A1.1 整机由哪些模块组成

**要回答的问题：** 参考如何经过 PD/CP/Filter 改变 VCO？反馈分频 N 和输出分频 D 如何区分？

**主教材：**
- JKU §7.1 Fig.74 PLL block diagram：作为章节主图，按 Reference、PD、LPF、VCO、Feedback Division 的关系逐项中文解释。
- 采用 JKU §7.1 的频率锁定关系 f_out = N f_ref，注明原图模型中的输出定义。
- 补充 ADI ADF4351 Fig.1 产品框图作为产品对应材料（公开嵌入要先核许可）。

**页面顺序：**
1. JKU 为什么需要 PLL 的论述（来自振荡器稳定性/可调性的矛盾）。
2. Fig.74 原图和逐块中文导读。
3. JKU 的锁定频率关系和符号解释。
4. ADF4351 产品框图对照：说明还有输出 Divider、Prescaler、配置寄存器等复杂性。
5. 现有可点击框图、Guided Tour 和 R/N/D 频率计算器。
6. 检查题：哪个节点决定反馈频率？哪个决定最终外部输出？

**必须保留的交互：** A-INT-01 全部节点点击、信号路径高亮、频率计算及重置。

**技术防错：** JKU 基本框图的 f_out 定义不自动等于带独立 Output Divider 的实际器件 RFout；在页面并列显示时必须解释二者节点不同。

### 4.2 A1.2 锁之前与锁之后

**要回答的问题：** 为什么近锁模型能给出误差曲线？什么地方开始不能再使用该模型？

**必须优先解决的来源/模型匹配问题：**

- JKU §7.1 Fig.76 和 Eq.62–64 是 **Type-I / 简单 PD + LPF + VCO** 的小信号模型。
- 现在 A1.2 已实现的曲线按照 **理想二阶 Type-II 近锁行为模型**组织。
- 两者**不是同一个系统**，不能把 JKU Fig.76/Eq.62–64 直接写成现有 Type-II 曲线的推导出处。
- JKU §7.2 Fig.83 及其 CP-PLL 类型和传递关系可以用来引出 Type-II，但须核对对应公式号、环路滤波器模型和初始条件。
- 必须在正文中分别标注“JKU 原文 Type-I 示例”和“本课程 Type-II 教学模型”，说明为什么响应类型可能相似而具体模型不同。

**建议页面顺序：**
1. 从 JKU Fig.74 闭环理解引出锁定概念。
2. JKU §7.1 的 Fig.76 与原式作为“线性化小信号分析方法”的原始来源；标明 Type-I。
3. 对比 JKU §7.2 Fig.83 对应的 Type-II CP-PLL，解释多一个积分器的意义。
4. 现有 Type-II 三曲线示波器，标明这是“本课程简化二阶 Type-II 模型”，列出真实模型使用的响应公式、初始条件和已忽略效应。
5. 用时间游标读 Δf、ΔVCTRL、Δφ，并说明三者单位不同。
6. 引用 JKU “小信号模型不描述完整捕获”的限制；完整逐边沿捕获在 C2/LOOP-01。

**必须保留的交互：** A-INT-02 预设、三曲线、共享时间游标、播放/暂停/单步/重置。

**特别验收：** 原作者的 Type-I 方程绝不标成 Type-II 的直接来源；量纲和初始相位条件与现有计算严格一致。

### 4.4 A2.1 时间差怎样变成相位差（首个样板）

**要回答的问题：** 为什么两个上升沿相差 Δt 就对应一个相位差？

**原教材主来源：**
- JKU RFIC §7.1，原始相位式：
  Δφ = 2π · Δt / T_ref。
- 必须在原式附近直接链接 JKU 原文，采用原教材变量及同一符号的中文解释。
- 本课程可统一定义 Δt = t_FB − t_REF、Δφ = φ_REF − φ_FB；如果原文未对正负号做同样的明确约定，标注“本课程符号约定”，不要说原作者如此定义。
- JKU Fig.75 的 XOR PD 时序只在解释“这段时间差如何由 PD 检测”时有教学必要才纳入，不为了凑图而加入。

**页面顺序（样板必须严格实施）：**
1. 标题与学习目标（2～3 行）。
2. “原教材公式”区：保留 JKU 相位公式和准确引用。
3. “中文解读”：2π 是一整圈，Δt/T_ref 是本周期的比例；把时间和相位的单位关系说清。
4. “本课程例子”：100 MHz、T=10 ns、Δt=40 ps、Δφ≈0.02513 rad≈1.44°。
5. “验证原公式”：移入原来已做好的双时钟拖动和相位圆盘；旁边实时显示刚才的原公式数值，不再先塞一整大块预测题。
6. “思考/验证”：200 MHz、40 ps 时是否变为 2.88°？
7. JKU 原始章节链接与译写署名。

**必须保留的交互：** A-INT-04 双时钟拖动、相位圆盘、固定时间差/固定相位模式、准确输入和 Reset。

**明确禁止：** 不新建与已存在动态边沿图重复的静态原理图；不把等式仅写为普通文本“fREF、Tref”而没有斜体、上下标。

**样板验收：** 打开后，读者先看到原式与中文解释，清楚知道下面的实验验证什么；原动态交互正常且数值对齐。

### 4.5 A2.2 频差怎样积成相位差

**要回答的问题：** 为什么恒定频差会产生持续增长的未包裹相位差？

**主来源：**
- JKU §7.1 的 PLL vs FLL 解释：频率是相位随时间的变化率。
- JKU §6.7 振荡器相位由瞬时角频率积分得到的关系；与本页用的 Δφ(t) 关系相连。
- 教材给出的一般角频率/相位关系与本课程的频差积分例子之间的推导过程必须清楚标明。

**页面顺序：**
1. 引用 JKU 原始物理关系及公式；解释角频率和相位的微积分关系。
2. 中文推导：Δφ(t)=Δφ(0)+2π∫₀ᵗ[f_REF(τ)−f_FB(τ)]dτ。
3. 本课程示例：Δf=+2 kHz、持续 1 ms、初始 +0.15 cycle，得未包裹 +2.15 cycles、模相位 +0.15 cycle。
4. 现有动态未包裹/模相位曲线和时间游标，用于验证上述推导。
5. “模相位回卷不是自动产生真实 Cycle Slip”提示和检查题。

**必须保留的交互：** A-INT-05 正负频差、初始相位、时间游标、动态曲线、Reset。

**技术防错：** 原文公式与本课程推导要标明谁是谁；不把 JKU 未明确给出的新关系伪装成 JKU 的原式编号；模相位跳变是表示方式。

### 4.6 A2.3 PLL 第一次怎么纠偏

**要回答的问题：** REF/FB 两路边沿的先后，如何经过 PFD 变成 UP/DN 的不同脉宽？

**主来源：JKU §7.2 PFD 四种工况**

- Fig.77：PFD 两触发器与复位结构。
- Fig.78：REF 领先 FB。
- Fig.79：FB 领先 REF。
- Fig.80：两路同相同频。
- Fig.81：存在较大频差、短期某一周期可能出现反方向、但平均趋势仍会指示正确纠偏方向。

**页面顺序：**
1. Fig.77 原始 PFD 电路，中文解释两个触发器、UP、DOWN 和 reset。
2. Fig.78～81 按四种工况组织为原图案例（可用合适授权的原图/受限时提供定位链接）；每种说明输入边沿、PFD 状态和下一步纠偏方向。
3. JKU 原文对 PFD 与 XOR PD 的区别：PFD 可以响应持续频率差。
4. 现有 Step/Play PFD 事件状态机，切换四种预设再现原图的行为。
5. 多周期模式的 f_REF/f_FB 频差及 UP/DN 脉宽变化；标明 reset delay 和理想模型边界。
6. 连接至 C1.1 / C1.2，继续学习详细电路及电荷泵。

**必须保留的交互：** A-INT-06 单次/多周期、事件时序、PFD 状态、reset delay、UP/DN、重置。

**技术防错：** 不能把“单次谁先到”解释为“单次测出频差”；也不能声称短时间一定每周期都输出正确频率方向，JKU Fig.81 正是边界反例。
