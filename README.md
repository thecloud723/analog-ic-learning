# Analog IC Learning

面向数字电路工程师的模拟与混合信号电路入门课程。

本仓库长期维护课程大纲、独立教学页面、交互实验、工程案例和参考资料。目标是帮助数字电路工程师建立模拟电路与混合信号系统的整体认识，能够阅读真实模拟 IP 的结构、理解控制接口，并读懂设计指标和测试报告。

## 课程原则

- **原理与工程实现并重**：基础原理图、真实论文/工业产品结构、测试结果与校准流程相结合。
- **公式规范**：独立公式与行内变量采用标准数学排版；上下标、变量斜体和描述性下标保持一致。
- **独立页面**：每个知识点拆成可独立打开的 HTML 页面，支持离线使用。
- **交互验证**：通过预测题、参数滑块和结果曲线验证物理因果关系。
- **来源可追溯**：记录教材、论文、数据手册和应用笔记的标题、图号、链接及引用要求。
- **模型边界明确**：教学模型、论文仿真结果和芯片实测数据分别标注。
