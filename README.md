# Analog IC Learning

面向数字电路工程师的模拟与混合信号电路入门课程。

本仓库用于长期维护课程大纲、独立教学页面、交互实验、工程案例和参考资料。课程以工程师阅读实际模拟 IP、理解电路结构与性能指标为目标，不采用面向初学学生的泛化科普写法。

## 课程原则

- **原理与工程实现并重**：每个重要模块同时覆盖基础原理图、真实论文/工业产品结构、测试结果与校准流程。
- **公式规范**：独立公式与行内变量均采用标准数学排版；变量斜体，描述性下标正体。
- **独立页面**：每个知识点拆成可独立打开的 HTML 页面，支持离线使用。
- **交互验证**：通过预测题、参数滑块和结果曲线帮助学习者验证因果关系。
- **来源可追溯**：记录论文、教材、数据手册、应用笔记的标题、图号、链接和许可/引用要求。
- **模型边界明确**：教学模型、论文仿真结果和芯片实测数据必须明确区分。
