# 版本管理规范

## 仓库作为唯一正式版本源

GitHub 仓库是课程的正式版本源。聊天中生成的 ZIP 只作为临时交付，不作为长期版本依据。

## 文件组织

- 每个专题有独立目录。
- 每章独立 HTML，必要时配套图片、SVG、数据和参考资料。
- 专题入口由 `index.html` 提供。
- 章节文件名采用稳定编号，避免频繁改名。
- 公式、文字或案例修订优先修改对应章节，不覆盖无关章节。

## Commit 约定

- `docs:` 文档和目录维护
- `feat(pll):` 新增 PLL 内容
- `fix(pll):` 修复公式、图形、交互或技术错误
- `refactor(pll):` 页面结构调整
- `feat(serdes):` 新增 SerDes 内容

每次提交说明涉及章节、主要变更和验证情况。涉及较大批次时，更新专题进度与 CHANGELOG。

## 发布验收

1. 文件路径及链接存在。
2. 单章可独立打开。
3. 专题入口可跳转。
4. 离线状态下公式、图片和交互正常。
5. 桌面与手机布局检查。
6. 动态公式、答案解析和滑块结果检查。
7. 来源和模型假设可追溯。
