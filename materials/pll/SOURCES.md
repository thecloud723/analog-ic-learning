- JKU source repository and Apache-2.0 license: https://github.com/iic-jku/radio-frequency-integrated-circuits
- ADI MT-086: https://www.analog.com/media/en/training-seminars/tutorials/MT-086.pdf
- ADI ADF4351 datasheet: https://www.analog.com/media/en/technical-documentation/data-sheets/adf4351.pdf
- TI SNAA106C: https://www.ti.com/lit/ml/snaa106c/snaa106c.pdf
- TI SNAA336A: https://www.ti.com/lit/an/snaa336a/snaa336a.pdf
- ADI PLL Fundamentals: https://www.analog.com/en/resources/analog-dialogue/articles/phase-locked-loop-pll-fundamentals.html

Downloaded source files must be kept under `materials/pll/source-pdfs/<source>/` or `materials/pll/originals/<source>/`. Page-used copies belong under `pll/assets/`; HTML files reference only those local copies. Keep original citation, figure number/page, license, download date, and any crop/resize note with each image. Vendor documents and paper figures are not automatically cleared for redistribution because the repository is private.
